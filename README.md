# AI 知识视频工坊

把“主题 + 你的观点 + 参考资料”变成横版长视频和竖版短视频。**大模型只写稿和分镜，默认整条视频只调用 1 次**；配音、画面、字幕时间轴和合成都在本机完成，渲染多少遍都不再花 token。

Windows 和 macOS 都能运行（Linux 也可以）。界面在浏览器里打开，后台是本机 Python 服务，只监听 127.0.0.1。

这个应用按《AI知识类视频生意调研报告》里的“路径三：代码生成动画”和补充五“配图配错怎么治”来做，参考了 Codex 版“内容视频工坊”的调用链（本机服务 → 逐句配音 → 采样数定时间轴 → Pillow 画帧 → FFmpeg），但改成了跨平台实现。

## 快速开始

### 方式一：双击启动脚本（需要 Python 3.9+）

| 系统 | 操作 |
| --- | --- |
| macOS | 双击 `start-mac.command`。被系统拦截时：右键 → 打开。 |
| Windows | 双击 `start-windows.bat`。安装 Python 时勾选 “Add python.exe to PATH”。 |

第一次运行会自动建虚拟环境 `.venv` 并安装依赖（Pillow、imageio-ffmpeg、certifi），约 1 分钟。之后直接启动。启动后浏览器自动打开；关掉命令行窗口或点页面右上角“退出”即可关闭。

### 方式二：命令行

```bash
pip install -r requirements.txt
python run.py            # 自动打开浏览器
python run.py --window   # 独立窗口（需 pip install pywebview）
```

### 方式三：免安装包

仓库的 GitHub Actions 会在 Windows 和 macOS 上各打一个包（Actions → build → Artifacts）。解压后双击 `AIVideoStudio`（Windows 是 `AIVideoStudio.exe`），不需要装 Python 和 FFmpeg。也可以自己打包：

```bash
pip install -r requirements.txt pyinstaller
python packaging/build.py      # 在哪个系统上运行就打出哪个系统的包
```

### 第一次使用要设置的

1. **设置 → 文案模型**：选预设（DeepSeek、硅基流动、通义千问、Kimi、智谱、火山方舟、本地 Ollama），填 API Key，点“测试连接”。任何 OpenAI 兼容的 Chat Completions 接口都能用。
2. **设置 → 配音**：默认用系统自带语音（macOS 的婷婷、Windows 的慧慧），免费离线，点“试听”。想要更自然的声音，改用云端 TTS（硅基流动 CosyVoice2 / IndexTTS-2，可以填你克隆的音色 ID）。
3. 可选：把背景音乐放进“音乐文件夹”，把授权清晰的图片导入“素材库”。

## 工作流程

| 步骤 | 页面 | 谁做 | 说明 |
| --- | --- | --- | --- |
| 1 选题 | 创作 | 你 | 主题、受众、时长、系列名，**3–5 句你自己的观点**，粘贴参考资料 |
| 2 写稿+分镜 | 创作 | 模型，1 次调用 | 一次拿到：标题、5 个封面标题、简介、标签、全部分镜、事实清单、竖版精简版选镜 |
| 3 修改 | 分镜 | 你 | 改口播、换画面类型、调顺序；右侧实时预览横竖两版；可对单镜“AI 改写”（1 次小调用） |
| 4 审片 | 审片 | 程序 + 你 | 风险提示、核对低把握度事实、读音清单、逐镜总览、点掉配错的图 |
| 5 出片 | 导出 | 程序 | 横版完整版（YouTube/B站）、竖版精简版（抖音/视频号/Shorts）、竖版完整版 |
| 6 发布 | — | 你 | 手动发布，勾选平台的 AI 内容声明 |

不想用模型时有两条零 token 的路：在创作页**粘贴自己的稿子**按段落自动切分镜，或**导入分镜 JSON**（格式见应用内“说明”页，可以在网页版聊天里生成后粘贴进来）。

每次导出的文件夹里有：MP4、SRT 字幕、口播稿、横竖两张封面、`发布信息.txt`（标题、简介、AI 声明文案、标签、发布前检查清单）和项目快照。

## 怎么省 token

- **一次调用出全部结果**：文案、分镜、画面类型、英文配图描述、事实清单合在一次请求里，按固定 JSON 输出。超过 6 分钟的视频才分“大纲 + 每章一次”。
- **固定提示词放最前面**：系统提示词一字不变，DeepSeek 等服务商的前缀缓存按缓存价计费（flash 缓存价约为正常输入价的 2%）。
- **本地缓存**：相同请求不会再发；改一句口播只重配那一句（配音按文本哈希缓存）。
- **模型不碰画面**：没有文生图、文生视频调用。
- 分镜页顶部显示每个项目实际调用了几次、花了多少钱（单价在设置里改）。

## 画面模板

11 种模板，全部由 Pillow 在本机绘制，文字、代码、公式、数字不会画错。三套主题（深色科技 / 浅色纸张 / 蓝白课堂）避免每条视频长得一样。

| 类型 | 用于 | 动态 |
| --- | --- | --- |
| 标题卡 | 开场、章节 | — |
| 要点列表 | 并列要点 | 随口播逐条出现；口播提到哪条就强调哪条 |
| 关键词卡 | 抽象概念、人名、机构 | — |
| 关键数字 | 一个数据 | — |
| 代码 | 代码片段，语法高亮，可强调行 | — |
| 流程图 | 步骤、因果链 | 逐个节点点亮 |
| 图表 | 柱状图 / 折线图 | 逐个柱子/点出现 |
| 对比 | 两栏对比 | 先左后右 |
| 表格 | ≤4 列 5 行 | 逐行出现 |
| 引语 | 你的观点 | — |
| 配图 | 具体事物 | 来自素材库 |

## 配图为什么不容易配错

1. **先分流**：模型给每镜标类别（具体事物 / 抽象概念 / 数据 / 人名机构），只有“具体事物”才配图，其余用文字卡和图表。
2. **英文画面描述**：配图镜头附一句 8–12 个英文词的描述，和素材库图片的标签比对打分。
3. **及格线**：最高分低于及格线（默认 0.34）就不用图，退回文字卡。宁可没图，不要错图。
4. **不重复**：同一条视频内、最近 30 个项目里用过的图不再用。
5. **越用越准**：审片时手动选中的图会加分。
6. **可选 Pexels**：本地库没有合适的图时，用 Pexels 接口（免费、授权清晰）按英文描述搜图，连同描述存进素材库。

素材库只放授权清晰的图（自己拍的、Pexels/Pixabay、AI 生成的），不要放从搜索引擎抓的图。

## 合规提示（本地规则，不调用模型）

审片页会标出：具体证券代码、买卖/荐股措辞、承诺收益、引流加群、虚拟货币交易、医疗疗效、绝对化用语、涉企负面措辞；没写作者观点、镜头类型过于单一、和最近项目结构高度相似、低把握度事实未核对、未勾选 AI 声明。画面角落默认标注“AI 辅助制作”。

应用**不提供自动发布**：公众号明文禁止用 AI 和脚本替代真人发布，抖音打击群控和矩阵批量发布。规则提示只是匹配关键词，不是法律意见。

## 配音引擎

| 引擎 | 平台 | 费用 | 说明 |
| --- | --- | --- | --- |
| 系统语音 | macOS `say` / Windows SAPI | 免费 | 自动选中文语音；Windows 需要系统装有中文语音包 |
| 云端 TTS | 全平台 | 按字计费，5 分钟约 0.2 元 | OpenAI 兼容的 `/audio/speech`，默认硅基流动 CosyVoice2，可用克隆音色 |
| edge-tts | 全平台 | 免费 | `pip install edge-tts`；非官方接口，稳定性和商用授权无保证 |
| 静音占位 | 全平台 | — | 只看排版和时间轴 |

读音不对的词在“设置 → 读音替换”里加一行（如 `GPU=G P U`），只影响配音，字幕保持原文。

## 代码结构

```
run.py                启动：本机服务 + 打开浏览器
studio/
  server.py           本机 HTTP 接口（随机令牌、只认 127.0.0.1、视频 Range 播放）
  jobs.py             任务管理：同一时间只跑一个生成/渲染任务，可取消
  pipeline.py         生成文案、零 token 切分镜、渲染成片、发布信息
  prompts.py          提示词（系统提示词固定，便于前缀缓存）
  llm.py              OpenAI 兼容客户端：本地缓存、重试、用量与费用
  tts.py              配音引擎；统一转成 24kHz WAV 并缓存
  visuals.py          11 种画面模板、三套主题、字幕、封面；预览和成片共用
  images.py           素材库、配图打分、不重复、Pexels
  compliance.py       合规规则、读音清单
  project.py          项目字段校验与规整（模型输出和页面保存走同一套规则）
  textutil.py         拆句、读音替换、文本相似度
  media.py            FFmpeg 查找、可取消的子进程、WAV 读写
  settings.py         设置；密钥单独存放，不经接口返回页面
  web/                页面（原生 HTML/CSS/JS，无需构建）
tests/test_studio.py  单元测试 + 端到端测试（假模型接口 + 真 FFmpeg 编码）
packaging/build.py    PyInstaller 打包
```

渲染一条视频的调用链：分镜按标点拆成句块 → 每句配音并转成 24kHz WAV → 用采样数算每句起止时间（字幕和画面共用这条时间轴）→ 每句画一帧（要点随口播展开）→ 写 ffconcat 时间线 → FFmpeg 合成 H.264/AAC MP4。

运行数据（项目、素材库、缓存、设置）放在用户目录，不写进程序目录：

- Windows：`%APPDATA%\AIVideoStudio`
- macOS：`~/Library/Application Support/AIVideoStudio`

API Key 存在其中的 `private/secrets.json`（macOS 上权限 600），页面只能看到“已设置/未设置”。

## 测试

```bash
python -m unittest discover -s tests -v
```

端到端测试会启动一个本机假模型接口，验证：只调用 1 次模型、第二次命中缓存、云端配音转码与缓存、横版和竖版精简版真实编码、字幕时间不超出视频、取消任务、接口令牌和路径穿越防护。

## 已知限制

- 画面是“每句一张图”的切换加逐条展开，不是连续动画；需要算法动画时可以用 Manim 单独渲染片段后在剪辑软件里替换。
- 字幕按句块对齐，不是逐字。
- 没有接入本地图文匹配模型（Chinese-CLIP）；配图打分用标签匹配，打分函数在 `studio/images.py` 的 `score`，可替换。
- Windows 系统语音依赖已安装的中文语音包；没有时改用云端 TTS 或 edge-tts。
- macOS 免安装包没有签名，第一次打开需要右键 → 打开。
