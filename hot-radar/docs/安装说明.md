热点雷达 1.0.0（基于开源项目 TrendRadar 6.11.0，GPL-3.0）。完整说明在应用内「使用指南」，或 [01 使用指南](<01 使用指南.md>)。

## macOS（Apple 芯片）

1. 打开 `HotRadar-1.0.0-macOS-arm64.dmg`，把「热点雷达」拖进「应用程序」。
2. 第一次打开：在「应用程序」里**右键「热点雷达」→「打开」**→ 再点「打开」。（应用没有 Apple 签名；也可以到「系统设置 → 隐私与安全性」点「仍要打开」。）
3. 以后在「应用程序」或启动台里直接打开。
4. 退出：关闭窗口、⌘Q 或界面右上角「退出」，后台任务全部停止。
5. 卸载：把「热点雷达」拖进废纸篓；数据在 `~/Library/Application Support/HotRadar/`，需要时手动删除。

## Windows（x64）

1. 双击 `HotRadar-Setup-1.0.0-x64.exe`。SmartScreen 提示时点「更多信息 → 仍要运行」。
2. 按提示安装（装到 `%LOCALAPPDATA%\Programs\HotRadar\`，不需要管理员权限），开始菜单和桌面会有「热点雷达」。
3. 免安装：解压 `HotRadar-1.0.0-windows-x64.zip`，双击 `HotRadar\HotRadar.exe`。
4. 退出：关闭窗口（×）、Alt+F4 或界面右上角「退出」，后台任务全部停止。
5. 卸载：「设置 → 应用」或开始菜单「卸载热点雷达」；数据在 `%LOCALAPPDATA%\HotRadar\`，卸载后保留。

## 用之前要知道

- 热榜数据来自第三方公开接口 **newsnow**（不是各平台官方接口），可能限流或停止服务；连不上时对应平台显示「失败」。网络不通时可以先点「离线演示」看效果。
- 推送（飞书、钉钉、企业微信等）和 AI 分析都是可选的，在「配置」里填写；地址和 Key 只保存在本机。
- 定时抓取只在窗口开着时进行（可以最小化），关窗即停止。
- 本软件按 GPL-3.0 发布，完整源码在应用内「使用指南 → 源码」可查看和下载。
