热点雷达是开源项目 **TrendRadar**（<https://github.com/sansan0/TrendRadar>，GPL-3.0）的桌面版：把它聚合微博、知乎、抖音、B 站、百度等热榜和 RSS，按关键词或 AI 筛选，生成 HTML 报告并推送到飞书/钉钉/企业微信等的能力，装进一个 macOS / Windows 应用窗口里，不用命令行、不用装 Python。引入它的目的是和用户自己做的「舆情监控系统」对比，对比结论见第 04 篇。

## 怎么安装和打开

| | macOS（Apple Silicon） | Windows（x64） |
| --- | --- | --- |
| 下载 | Releases 页面的 `HotRadar-1.0.0-macOS-arm64.dmg` | `HotRadar-Setup-1.0.0-x64.exe`（或免安装 zip） |
| 安装 | 打开 dmg，把「热点雷达」拖进「应用程序」 | 双击安装程序，装到 `%LOCALAPPDATA%\Programs\HotRadar\`，不需要管理员权限 |
| 首次打开 | 没有签名：在「应用程序」里右键 →「打开」，或「系统设置 → 隐私与安全性」点「仍要打开」 | SmartScreen 提示时点「更多信息 → 仍要运行」 |
| 以后打开 | 「应用程序」或启动台里的「热点雷达」 | 开始菜单或桌面的「热点雷达」 |
| 退出 | 关闭窗口（红色按钮）、⌘Q、界面右上角「退出」 | 关闭窗口（×）、Alt+F4、界面右上角「退出」 |

完整说明（首次准备、关窗与最小化的区别、数据位置、故障处理）见 [01 使用指南](<01 使用指南.md>) 第 1 节；只想装上用，看 [安装说明](<安装说明.md>)。

## 四样东西不要混

| 东西 | 在哪 | 能做什么 |
| --- | --- | --- |
| 源码目录 | 仓库 `hot-radar/`（外壳 `hotradar/`、上游 `upstream/`、文档 `docs/`、打包 `packaging/`、测试 `tests/`） | 阅读、修改、重建；有 Python 3.12 时可 `python run.py` 直接运行 |
| 安装包 | Releases 页面的 `.dmg` / `Setup.exe` / 免安装 zip | 安装后日常使用；包里附带全部文档和源码（只读） |
| 运行数据目录 | macOS `~/Library/Application Support/HotRadar/`，Windows `%LOCALAPPDATA%\HotRadar\` | 你的配置、关键词、密钥、抓取历史和报告；换新版本、卸载都保留 |
| 文档 | 仓库 `hot-radar/docs/`，同步到 Obsidian 的 `Claude/热点雷达/` | 与应用内「使用指南」同一份 |
