> 这篇给想学 RSSHub「原本怎么用」的读者：先讲它是什么，再一步步演示它的原版操作，最后和舆情监控的「订阅目录」逐步对照。应用里左侧导航「RSSHub 原版」页就是这篇的配套练习场。

## 1. 先弄清楚：RSSHub 没有「操作界面」

**结论**：RSSHub 是一个**后台服务**，不是一个带按钮的应用。打开 `http://127.0.0.1:1200` 只能看到一个欢迎页（「Welcome to RSSHub!」），没有搜索框、没有订阅列表。

打个比方：RSSHub 像一家**只接电话订单的翻译社**。你打电话报一个「订单号」（路由，比如 `/cls/telegraph`），它就派人去财联社网站把最新电报抄下来，翻译成统一格式（RSS），交给你。翻译社自己没有门面，**找订单号要去看它的价目表**（文档站），**收到的稿子要用别的工具看**（RSS 阅读器）。

所以人们常说的「RSSHub 的界面」，其实是三样东西拼起来的：

| 东西 | 作用 | 在哪 |
|---|---|---|
| 文档站 | 按分类列出全部路由（订单号），每条写清参数、例子、是否要 Cookie | <https://docs.rsshub.app/zh/>（有中文版） |
| RSSHub 服务本身 | 收到路由 → 现场抓网站 → 返回 RSS（XML 文本） | 本机 `http://127.0.0.1:1200` |
| RSS 阅读器 | 定时向 RSSHub 要新内容，排版好给人看 | Folo、Reeder、NetNewsWire、Inoreader 等，另装 |
| RSSHub Radar（可选） | 浏览器扩展：你逛某个网站时提示「这个网站有哪些路由可订阅」 | Chrome / Safari 扩展商店 |

**已证实**（2026-10-21 在本机检查）：本机 RSSHub 首页允许被别的页面嵌入，所以应用里能直接显示；官方文档站设置了 `x-frame-options: SAMEORIGIN`（只允许自己嵌入自己），所以应用里只能放一个「在浏览器打开」的按钮。

## 2. 原版操作：四步订阅一个网站

以「财联社电报」为例。

**第 1 步：在文档站找路由。** 打开 <https://docs.rsshub.app/zh/>，左侧按分类（社交媒体、新媒体、传统媒体、金融……）浏览，或者右上角搜「财联社」。找到「电报」这一条，会看到：

- 路由：`/cls/telegraph/:category?`
- 参数说明：`category` 是可选的分类：`watch` 看盘、`announcement` 公司、`red` 加红、`remind` 提醒、`fund` 基金、`hk_us` 港美股
- 例子：`https://rsshub.app/cls/telegraph`

路由里的写法要会读：`/:category` 表示这里要**填一个值**；后面带 `?` 表示**可以不填**；没有 `?` 就**必须填**。

**第 2 步：拼成地址。** 文档里的例子用的是官方公共实例 `rsshub.app`，它经常限流，所以换成本机：`http://127.0.0.1:1200/cls/telegraph`。

**第 3 步：浏览器打开看一眼。** 能看到一大段 XML 文本，里面 `<item>` 一条就是一篇文章，说明这个路由能用。看到错误页（503 等）就说明这个网站抓不到，常见原因见第 4 节。

> 应用里「RSSHub 原版」页就是这一步：输入路由，点「预览原始 RSS」，下面显示的就是 RSSHub 原样返回的内容。

**第 4 步：放进阅读器。** 把地址复制到 RSS 阅读器的「添加订阅」里。之后阅读器每隔一段时间去要一次新内容。

## 3. 原版和舆情监控「订阅目录」的对照

| 原版步骤 | 原版怎么做 | 舆情监控里怎么做 |
|---|---|---|
| 找路由 | 文档站按分类翻、搜索（英文分类名，部分说明是英文） | 「订阅目录」左侧同样的分类（名称译成中文），顶部搜索；条目数据**直接从本机 RSSHub 读取**，和本机版本一致 |
| 判断能不能用 | 自己看文档里的提示框（需要 Cookie、需要 Puppeteer 等） | 每条自动标出「需 Cookie/配置」「需内置浏览器」「有反爬」「需填参数」，可勾「只看免配置」 |
| 拼地址 | 自己把参数填进路由，换成本机地址 | 免参数的直接「订阅」；要参数的点「填参数订阅」，按参数名逐个填，有「用例子」按钮 |
| 试一下 | 浏览器打开看 XML | 「测试」按钮显示抓到几条、前 8 条标题；「测试本页」批量测；结果会记住 |
| 放进阅读器 | 复制到阅读器 | 「订阅」后成为一个数据源，按间隔自动抓取，并做情感打分、匹配监控对象、预警 |
| 看文章 | 在阅读器里看 | 「资讯流」「总览」「预警中心」 |

两边各有道理：

- **原版的好处**：路由和阅读器分开，换阅读器不影响订阅；文档站写得很全，有每条路由的维护者、更新时间、参数细节；阅读器专注阅读体验（排版、已读、收藏）。
- **舆情监控的好处**：一个窗口做完找、试、订阅、看；订阅之后不只是阅读，还会**按你关心的股票和关键词过滤、打情感分、发预警**，这是阅读器不做的。

想试原版：照第 2 节做一遍，阅读器可以先试本机 RSSHub 欢迎页里推荐的 Folo（欢迎页的「Try Folo」按钮）。

## 4. 常见报错怎么读

| 现象 | 意思 | 怎么办 |
|---|---|---|
| 连不上 `127.0.0.1:1200` | RSSHub 没有运行 | 应用「订阅目录」或「RSSHub 原版」页点「启动 RSSHub」；或终端运行 `zsh ~/Projects/第三方开源/启动.sh rsshub` |
| 503 Service Unavailable | RSSHub 运行了，但这个网站抓不到 | 常见于需要登录 Cookie、有反爬验证或要内置浏览器的网站（小红书、抖音、微博搜索、雪球个股等）。本应用**不绕过**登录和反爬，这类源先不订阅 |
| 404 | 路由不存在 | 路径或参数写错，或本机 RSSHub 版本太旧（`cd ~/Projects/第三方开源/RSSHub && git pull` 后重启） |
| 能打开但 0 条 | 网站暂时没有新内容，或网站改版 | 隔一段时间再试；长期为 0 可到 RSSHub 的 GitHub 提 issue |

## 5. 本机 RSSHub 要定期更新

本机 RSSHub 是 2026-10-18 下载的一份快照，**不会自己更新**；到 10-22 已经落后社区 48 个更新。网站改版导致某个路由坏了，社区修好后，你本机要更新才用得上。

- 应用里：「订阅目录」或「RSSHub 原版」页顶部「检查 RSSHub 更新」→「更新 RSSHub」。
- 手动：终端里依次运行 `cd ~/Projects/第三方开源/RSSHub`、`git pull`、`pnpm install`、`pnpm build`，再重启 RSSHub。

原理：RSSHub 平时运行的是 `dist/` 里**编译好的**程序（`pnpm start` = `node dist/index.mjs`），所以光拉新代码不够，要重新编译、重启才会生效。

## 6. 许可证与合规

- RSSHub 是开源软件，许可证 **AGPL-3.0**。本机自用没有任何义务；只有修改它的代码后再分发、或架成网站给别人用时，才需要公开修改后的源码。
- 舆情监控**只通过 HTTP 调用**本机 RSSHub，没有复制它的代码，所以两者是独立程序，舆情监控不受 AGPL 约束。RSSHub 也不随舆情监控一起打包。
- 许可证管的是「代码怎么用」；**网站让不让抓**由各网站的使用条款决定。个人低频使用风险小；抓取间隔别设太短。

## 读完你应该懂了什么

- RSSHub 是「把网站变成 RSS 的后台服务」，本身没有操作界面；原版体验 = 文档站 + 本机服务 + 阅读器。
- 路由写法：`:参数` 要填，带 `?` 的可不填。
- 舆情监控的订阅目录把「找路由、判断能不能用、拼地址、试、订阅」合在一个页面里，订阅后还做打分和预警。
