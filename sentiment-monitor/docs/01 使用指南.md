## 1. 怎样开始和结束

### 安装和首次打开

| | macOS（Apple Silicon，M 系列芯片） | Windows（x64） |
|---|---|---|
| 安装 | 打开 `SentimentMonitor.dmg`，把 `SentimentMonitor.app` 拖进「应用程序」 | 运行 `SentimentMonitor-Setup.exe`（装到 `%LOCALAPPDATA%\Programs\SentimentMonitor\`，不需要管理员权限，开始菜单和桌面有快捷方式）；也可解压免安装文件夹直接运行 |
| 首次打开 | 应用没有签名：在「应用程序」里右键 → 打开；或「系统设置 → 隐私与安全性」点「仍要打开」 | SmartScreen 拦截时点「更多信息 → 仍要运行」 |
| 需要的外部程序 | Google Chrome 或 Microsoft Edge（用来显示应用窗口） | Microsoft Edge（Windows 10/11 自带）或 Chrome |
| 卸载 | 把 `.app` 拖进废纸篓 | 「设置 → 应用」或开始菜单「卸载舆情监控」；数据目录保留 |
| 首次准备 | 无需登录。首次打开后可在总览页点「生成演示数据」看效果，再到「监控对象」添加自己的股票或关键词 | 同左 |

不需要另装 Python。海外数据源（Google 新闻、Yahoo）需要在「设置 → 网络代理」里填代理；国内数据源直接可用。

### 打开后发生什么

1. 后台服务启动，监听 `127.0.0.1:8848`（被占用时自动换一个空闲端口），只有本机能访问。
2. 用 Edge 或 Chrome 的「应用窗口」模式（没有地址栏）打开页面，使用独立的浏览器配置目录，所以这个窗口是本应用启动的子进程。
3. 采集调度开始按各数据源的间隔抓取。

已经在运行时再次打开，不会启动第二个后台，只会再打开一个窗口。

### 关闭和退出

| 操作 | 结果 |
|---|---|
| 关闭应用窗口（macOS 红色按钮、Windows 右上角 ×），且这是最后一个窗口 | 后台在约 10 秒内停止（这 10 秒留给刷新页面），采集任务一起停止，端口释放 |
| macOS：在应用窗口按 ⌘Q 或菜单「退出」<br>Windows：Alt+F4、任务栏右键「关闭窗口」 | 应用窗口进程结束，后台检测到后立即停止 |
| 页面右上角「退出」按钮 | 后台停止采集、关闭应用窗口、释放端口 |
| 开着多个窗口时只关一个 | 不退出；最后一个窗口关掉后才退出 |
| 最小化、隐藏或切到其他应用 | 应用和后台继续运行，采集照常进行 |

- **本版本不提供「关窗后继续在后台采集」的常驻模式。** v0.1 设置页里的「关闭页面后自动退出后台」开关已经去掉；旧设置里即使关掉过，v0.2 也会按上表退出。如果需要 7×24 常驻采集，属于需要单独约定的功能（要说明资源占用和停止方法），目前**未实现**。
- **异常收尾**：后台崩溃或被强制结束时，页面在约 20 秒内显示「后台已退出」并尝试关闭窗口；应用窗口崩溃或被强制结束时，后台检测到窗口进程消失或页面断开超过 10 秒后自行退出。监测对象是应用窗口进程和页面的实时连接（SSE），用途只是判断要不要退出。
- 退出不会删除数据目录里的任何数据或设置。

## 2. 怎样完成主要任务

### 各页面用途

| 页面 | 用途 | 常用操作 |
|---|---|---|
| 总览 | 24 小时资讯量、利好/利空、情绪指数、风险信号；近 14 天趋势图；监控对象热度榜；最新预警 | 点热度榜里的对象跳到该对象的资讯 |
| 资讯流 | 全部资讯 | 按对象、情感、来源、时间、仅风险、关键词筛选；「导出 CSV」导出当前筛选结果（Excel 可直接打开） |
| 监控对象 | 要盯的股票或关键词 | 添加/编辑名称、代码、市场、别名、排除词；点一行看近 30 天趋势 |
| 数据源 | 已添加的抓取来源，**按分类折叠分组** | 点分组标题折叠/展开（会记住）；「整组启用/停用」；搜索框、「只看启用 / 只看失败」；单个源启用/停用、改间隔、「抓取」、编辑时「测试」只看结果不入库；「全部立即抓取」 |
| 订阅目录（v0.3） | 本机 RSSHub 的全部路由 + 直连源，按 RSSHub 的分类浏览 | 左侧选分类，顶部搜索；「只看免配置」「只看直连」；单条「测试」「订阅」；勾选多条后「订阅所选」；「测试本页」一次测当前页全部；带必填参数的点「填参数订阅」；RSSHub 没运行时点「启动 RSSHub」 |
| RSSHub 原版（v0.3） | 嵌入本机 RSSHub 自己的页面，对照学习它原本的用法 | 输入路由点「预览原始 RSS」看 RSSHub 原样返回的内容；「订阅到舆情监控」；「打开官方中文文档（浏览器）」；配套文章见 [09 RSSHub 原版用法说明](<09 RSSHub 原版用法说明.md>) |
| 预警中心 | 风险词、负面舆情、热度异动预警 | 「已读」「全部已读」 |
| 运行状态 | 本应用各进程的 PID 和内存 | 「刷新」；页面每 5 秒自动刷新 |
| 使用指南 | 全部项目文档和源码 | 左侧目录切换篇目；「源码」查看任意手写文件；「下载全部源码（zip）」 |
| 设置 | 浏览器、代理、情感阈值、预警规则、配色、保留天数 | 改完点「保存设置」 |

顶部栏：缩放控件、版本号、实时连接状态、「立即刷新」（让所有启用的数据源马上抓一次）、深浅色切换、「退出」。

### 最常用的顺序

1. 「监控对象」→ 添加股票（如 贵州茅台 / 600519 / A股），可填别名。
2. 「订阅目录」→ 左侧选「金融财经」，订阅想要的源（交易所公告、监管、快讯、热榜……）；或在「数据源」确认已有的源已启用。
3. 回到「总览」看趋势和热度；有预警时右下角弹提示，「预警中心」查看详情。
4. 「资讯流」按对象筛选，需要留存时「导出 CSV」，文件由浏览器保存到下载目录。

## 3. 数据从哪来、何时更新

> v0.3 新增的来源（RSSHub、热榜、巨潮、港交所、SEC、央行等）、时间口径、目录标记和「只存命中」的详细说明见 [05 数据口径与来源](<05 数据口径与来源.md>)。

- **来源**：新浪财经滚动新闻、东方财富 7×24 快讯、财联社电报、东方财富资讯搜索（网站页面自用的公开 JSON 接口，不是官方开放 API）；必应新闻、Google 新闻、Yahoo Finance、任意 RSS/Atom。行情（只用来显示涨跌）来自行情接口，30 秒缓存。完整表格见 [README](<../README.md>) 的「消息来源」。
- **自动更新**：每个数据源有自己的抓取间隔（数据源页可改，快讯类建议 3–5 分钟，搜索类 15–60 分钟）。调度线程每 10 秒检查一次哪些源到期，每轮最多同时开始「设置 → 同时抓取的数据源个数」个（默认 6），等得最久的先抓。
- **失败退避**（v0.3）：连续失败的源等待「间隔 × 2^失败次数」，最多 8 倍，成功一次恢复。
- **RSSHub**（v0.3）：RSSHub 类的源要本机 RSSHub 在运行。默认开启「自动启动 RSSHub」：有到期的 RSSHub 源而 RSSHub 没运行时，本应用用 `~/Projects/第三方开源/启动.sh rsshub` 启动它（最多每 10 分钟试一次）。RSSHub 是独立程序，**本应用退出时不会停止它**（它可能也在给别的程序用），要停用 `zsh ~/Projects/第三方开源/停止.sh`。
- **手动更新**：顶部「立即刷新」或数据源页「立即抓取」。
- **去重**：同一链接或同一标题只入库一次。
- **保留**：超过「资讯保留天数」的资讯和预警每小时自动清理一次。
- **缺失、零与失败的区别**：
  - 数据源抓取失败：数据源页显示红色状态和具体报错，「上次成功」时间不变；其他数据源照常工作。
  - 抓取成功但没有新资讯：显示新增 0 条，这是正常的「零」。
  - 行情读不到：热度榜行情列显示「—」，不代表涨跌为 0。
  - 演示数据会标「演示数据」，可在设置页清空。

## 4. 结果如何理解

- **情感得分**：-1 到 1，界面显示为 -100 到 100。≥ 利好阈值（默认 0.15）判为利好，≤ 利空阈值（默认 -0.15）判为利空，其余中性。每条资讯显示命中的情感词，方便核对。
- **情绪指数**：当天所有资讯得分的平均值 ×100。
- **风险标签**：监管处罚、财务风险、股东减持、经营风险、法律诉讼、退市风险。
- **预警**：命中风险词（红色）；命中监控对象且得分 ≤ 负面阈值（默认 -40，黄色）；近 1 小时条数 ≥ 前 23 小时平均每小时条数 × 3 且至少 5 条（热度异动）。
- **已知限制**：词典法读不懂反讽和复杂语境；国内接口在网站改版后可能失效；只能看到各来源公开展示的资讯。大模型打分、企业微信/钉钉推送等**未实现**（见 [ARCHITECTURE](<ARCHITECTURE.md>) 的「扩展」）。

## 5. 出了问题怎么办

| 现象 | 检查路径 |
|---|---|
| 双击没反应 / 窗口没出现 | 看数据目录里的 `monitor.log`；确认装有 Edge 或 Chrome；在「设置 → 打开页面用」换成「系统默认浏览器」 |
| macOS 提示「无法打开」「已损坏」 | 右键 → 打开；或「系统设置 → 隐私与安全性 → 仍要打开」 |
| Windows SmartScreen 或杀毒软件拦截 | 「更多信息 → 仍要运行」；杀毒软件里把程序文件夹加入信任（未签名的 PyInstaller 程序常被误报） |
| 页面显示「与后台的连接断开」或「后台已退出」 | 后台已停止，重新打开应用即可；原因写在 `monitor.log` 末尾 |
| 订阅目录只有 90 条 / 提示「RSSHub 没有运行」 | 点「启动 RSSHub」，等 10–30 秒后刷新；或检查「设置 → RSSHub 地址」 |
| RSSHub 源报 503 | 目标网站需要 Cookie、有反爬或暂时打不开，见 [09 RSSHub 原版用法说明](<09 RSSHub 原版用法说明.md>) 第 4 节 |
| 某个数据源一直失败 | 数据源页「编辑 → 测试」看报错；海外源需要代理；国内接口报错多为网站改版或访问太频繁，调大间隔 |
| 数据没更新 | 看顶部连接状态是否「实时」；数据源是否启用、上次运行时间；点「立即刷新」 |
| 端口被占用 | 自动换端口，无需处理；页面地址写在日志里 |
| 关掉窗口后后台还在 | 正常情况 10 秒内退出；超过 1 分钟仍在，请把 `monitor.log` 发给维护者，可在活动监视器 / 任务管理器里结束 `SentimentMonitor` |

数据目录：macOS `~/Library/Application Support/SentimentMonitor/`，Windows `%APPDATA%\SentimentMonitor\`。

## 7. 当前进程与内存

主导航「运行状态」页列出本次启动涉及的每个进程：

| 列 | 含义 |
|---|---|
| 职责 | 后台服务 / 应用窗口（浏览器主进程）/ 应用窗口子进程（渲染、GPU、网络等） |
| 进程名、PID | 当前真实的进程号，每 5 秒重新读取 |
| 内存 | macOS 用常驻内存 RSS，Windows 用工作集（Working Set），单位 MiB（1 MiB = 1024² 字节） |
| 采样时间 | 这一行数值的读取时间 |

- **采集任务没有独立进程**：采集调度和抓取都是后台服务进程里的线程（1 个调度线程 + 最多 4 个抓取线程），线程共享后台的 PID，所以不会单独列出，也不能把线程数当进程数。
- **应用窗口**：由本应用启动的 Edge/Chrome 应用窗口及其子进程逐个列出。若页面是在系统默认浏览器里打开的，浏览器属于外部程序，不列入、不计入合计，页面会写明。
- **合计**：各进程内存直接相加，进程之间共享的内存可能被重复计算，所以合计会偏大。
- **读不到时**显示「暂不可用」，不会沿用旧值。Windows 上没有 psutil 时无法枚举应用窗口的子进程，会注明。
- **和系统工具对照**：macOS 打开「活动监视器 → 内存」，按 PID 查找；Windows 打开「任务管理器 → 详细信息」，按 PID 查找。任务管理器默认的「内存（专用工作集）」比这里的工作集小，需要在列标题右键 →「选择列」勾选「工作集（内存）」才能对上。

## 8. 怎样缩放界面

- 位置：页面顶部右侧，标题栏里紧凑的一组：「−」、百分比下拉框、「＋」、「100%」。
- 范围：70%–120%，每 5% 一档，共 11 档（70、75、80、85、90、95、100、105、110、115、120）。
- 选具体档位：点百分比下拉框直接选。
- 逐档调整：「−」每次减 5 个百分点，「＋」每次加 5 个百分点；到 70% 时「−」变灰，到 120% 时「＋」变灰。下拉框和按钮始终显示同一个值。
- 恢复：点「100%」按钮一键恢复默认。
- 作用范围：整个界面，包括侧栏、文字、按钮、表格、图表（缩放后自动重画）和使用指南里的文档、源码。
- 保留：选择保存在应用窗口的本地存储里，切换页面、刷新和下次打开都保留。
- 与系统缩放叠加：会叠加在 Windows 显示缩放（125%、150%）或 macOS 分辨率设置之上。窗口较窄时顶部按钮会自动换行，缩放控件仍在顶部。
