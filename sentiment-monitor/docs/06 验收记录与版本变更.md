## 版本与变更

| 版本 | 日期 | 改了什么 | 为什么 |
|---|---|---|---|
| 0.1.0 | 2026-10 上旬 | 首版：监控对象、8 种数据源、词典情感打分、风险词、预警、总览/资讯流、CSV 导出 | 用户要一个面向股票投资的本地舆情监控 |
| 0.2.0 | 2026-10-13 | 应用内「使用指南」（全部文档 + 源码查看/下载）、界面缩放 70–120%、运行状态（进程与内存）、关窗即停止后台；CI 改为 Windows + macOS，出 .dmg 和 Setup.exe | 统一交付要求 |
| 0.3.0 | 2026-10-21 | **订阅目录**：本机 RSSHub 全部路由（2066 网站 / 4008 条）按 RSSHub 自己的分类浏览、搜索、测试、订阅；90 个直连源（巨潮、港交所、SEC/EDGAR、美联储等央行、海外财经媒体、newsnow 热榜）；**RSSHub 原版**页；数据源页按分类折叠、整组启停、只看失败；失败退避（最多 8 倍）；「只存命中」；并发上限；RSSHub 自动启动；SEC 联系邮箱设置；TLS 断开重试；本机地址不走代理；旧库迁移（加 3 列，修正 2 个失效默认源）；文档新增 04 源码精读、05 数据口径、06、08 过程日志、09 RSSHub 原版用法说明；修复财联社电报接口改版导致的 404 | 用户要更多数据源（中国多、财经多、加交易所），并且不习惯 RSSHub 原本的用法 |
| 0.3.1 | 2026-10-22 | **按监控对象查公告**：巨潮（A 股、港股按代码）、SEC（美股、中概股按代码，默认近 90 天、不含 Form 4）；**检查 / 更新本机 RSSHub**（拉代码 → 装依赖 → 编译 → 重启，编译失败自动还原，有本地修改时拒绝）；按监控对象的源「测试」改用前 5 个对象；新增精读 02 篇 | 全市场公告靠标题匹配会漏、会错配；本机 RSSHub 是快照、不会自己更新 |
| 0.4.0 | 2026-10-22 | **改用原生窗口**（pywebview：macOS WKWebView、Windows WebView2），和其他应用一致；不可用时退回 Edge/Chrome；关窗/⌘Q/程序坞退出在 closing 事件里同步收尾（`App.stop_now`）；SIGTERM 也走退出流程；下载弹「存储为」、外部链接交系统浏览器、预警改由系统通知；macOS 程序名显示「舆情监控」；新增精读 03 篇 | 用户希望和其他应用一样；借 Chrome 时程序坞显示 Chrome、⌘Q 无法由 AI 验证、要求装 Chrome、内存大 |

## v0.4.0 验收记录（2026-10-22）

| 项目 | 方法 | 结果 |
|---|---|---|
| 单元测试 | `python -m unittest discover -s tests` | 55 项通过（新增：通知参数传递、原生模式进程表、`stop_now` 停服务关库且可重复调用、预警触发系统通知） |

| 页面「退出」按钮 | `POST /api/shutdown` | 2 秒结束，收尾完整 |
| SIGTERM | `kill -TERM` | 收尾完整，约 8 秒（要等窗口事件循环交还控制权） |
| macOS 程序名 | 读 Info.plist、`NSRunningApplication.localizedName` | 「舆情监控」，标识 `com.claude.sentiment-monitor`，版本 0.4.0 |
| 安装到 `/Applications` | 用户确认后替换 `舆情监控系统（Claude）.app`（第一次被 macOS「App 管理」拦截，用户给小写 claude 打开该权限后成功） | `/api/bootstrap` 返回 0.4.0、`native_window: true`；用户原有 11 个数据源保留；没有 Chrome 进程 |
| 系统通知 | 调用 `desktop.notify()` | 命令执行无错误；**是否弹出待用户确认** |
