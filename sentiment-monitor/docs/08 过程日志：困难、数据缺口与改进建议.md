### 2026-10-21　v0.3.0：订阅目录

**起因**：用户觉得数据源太少（9 个），想把 RSSHub 里热门的源搬进来，中国多、海外少、财经多，再加交易所（SEC、港交所、A 股交易所、巨潮）。用户不习惯 RSSHub 原本的用法（网页文档、英文、要配阅读器）。

**方案的演变**（都是用户在对话中确认的）：

1. 最初提议精选约 100 个源、按我们自己的类别分类。
2. 用户担心列表太长 → 改为分类浏览。
3. 用户问 RSSHub 一共有多少 → 实测本机 RSSHub 的 `/api/namespace`：2066 个网站、4008 条路由，并且自带分类 → 改为**运行时读取全部路由、按 RSSHub 自己的分类**，不另起分类；交易所等不在 RSSHub 里的作为「直连」源归入同样的分类。
4. 用户想学习 RSSHub 原版界面 → 查证后发现 RSSHub 本身没有操作界面（只有欢迎页），「原版体验」= 文档站 + 服务 + 阅读器 → 在应用里加「RSSHub 原版」页（嵌入本机 RSSHub、预览原始 RSS）和一篇原版用法说明，没有另做应用。
5. 舆情监控和热点雷达：建议分开（技术栈、依赖和许可证都不同），只借用热点雷达同款的 newsnow 热榜接口。用户同意。

**做了什么**：四种新数据源（RSSHub、newsnow 热榜、巨潮、港交所披露易）；90 个直连源；订阅目录页；RSSHub 原版页；数据源页按分类折叠；失败退避；只存命中；并发上限；RSSHub 自动启动；SEC 联系邮箱设置；旧数据库迁移；14 个新测试；批量实测脚本；文档 04/05/06/08/09。

**遇到的困难与处理**：

| 困难 | 怎么发现 | 处理 | 状态 |
|---|---|---|---|
| 小红书、抖音用户页、微博搜索、雪球热帖在 RSSHub 上 503 | 首轮实测 | 查源码：这些路由标了「需要 Cookie」「需要内置浏览器」「反爬」。按交付要求不绕过登录和反爬 → 社交平台改用 newsnow 热榜 | 已证实 |
| v0.2 默认的 36氪 官方 feed 返回 0 条 | 直连实测 | 改成 RSSHub `/36kr/newsflashes`（实测 20 条），旧数据库一次性迁移 | 已修 |
| v0.2 默认的 `rsshub.app` 公共实例常被限流 | 已知 | 改指向本机 RSSHub | 已修 |
| SEC EDGAR 返回 403 | 用应用代码测直连源 | 实测：冒充浏览器 403、只写程序名 403、程序名 + 邮箱 200。SEC 的 Fair Access 规定要写联系邮箱 → 加「设置 → SEC 联系邮箱」，没填时明确提示，不用假邮箱。用户朋友的 `sec_filings_downloader.py` 也是同样做法（UA 带 contact 邮箱） | 已修，**待用户填邮箱后验证** |
| 港交所官网 RSS 报 SSL `UNEXPECTED_EOF` | 8 线程并发实测 | 单独请求正常 → 判断是并发过多被 CDN 在 TLS 握手时挂断 → 对「连接被挂断」类错误等 1.5 秒重试一次 → 重测 3 个全部成功 | 已修（原因是推断，依据是单发正常、并发失败、重试成功） |
| 港交所创业板中文公告文件不存在 | 逐个文件名试 | 创业板只放英文版 | 已证实 |

| RSSHub 官方文档站不能嵌入应用 | 查响应头 | `x-frame-options: SAMEORIGIN` → 只能在浏览器打开；本机 RSSHub 没有这个限制，可嵌入 | 已证实 |

## 3. 技术上的坑

| 表现 | 原因 | 解决 |
|---|---|---|
| 403 Forbidden（SEC） | 对方「查证件」：UA 不合规 | 按对方规定改请求头 |
| SSL UNEXPECTED_EOF（港交所） | 对方「防挤」：并发太多，握手被挂断 | 降低并发 + 重试一次 |
| 请求本机服务失败（设了代理时） | 请求被发给代理软件 | `ProxyHandler({})` 挡住代理 |
| `CREATE TABLE IF NOT EXISTS` 不给旧表加列 | 表已存在时整句跳过 | `PRAGMA table_info` 检查 + `ALTER TABLE ADD COLUMN` |
| zsh 里网址带 `?` 报 `no matches found` | zsh 把 `?` 当通配符 | 网址加引号，或把网址放进文件用 Python 读 |
| 测试里中文网址报 `UnicodeEncodeError` | HTTP 请求行只能是 ASCII | `urllib.parse.quote` 编码 |
