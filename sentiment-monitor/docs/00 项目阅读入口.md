## 这是什么

舆情监控系统是一个本机运行的桌面应用：按你设定的监控对象（股票、行业、公司、人物等关键词），定时从财经网站和 RSS 抓取资讯，做中文情感打分、风险词识别和预警，在总览、资讯流、预警中心等页面里查看。所有数据保存在你自己电脑上的 SQLite 文件里，服务只监听 `127.0.0.1`。

- 当前版本：**v0.4.0**（界面右上角和左下角都显示版本号）
- v0.4.0：改用**应用自己的原生窗口**（和其他几个应用一样），不再借 Chrome；⌘Q、关窗、程序坞退出都由应用自己处理并当场收尾。
- v0.3.1 新增：**按监控对象查公告**（A 股、港股查巨潮，美股、中概股查 SEC，按代码精确对应）、**检查 / 更新本机 RSSHub** 按钮。
- v0.3 新增：**订阅目录**（本机 RSSHub 全部 4008 条路由按 RSSHub 自己的分类浏览 + 90 个直连源：巨潮资讯、港交所、SEC、美联储等交易所/监管/央行，微博、抖音、雪球等热榜）、**RSSHub 原版**页、数据源页按分类折叠、失败自动退避、量大的源「只存命中」
- 应用名称：舆情监控（安装包和程序文件名为 `SentimentMonitor`）
- 后台：本机 Python 服务（打包后不需要另装 Python）；界面：本机网页，显示在应用自己的原生窗口里（v0.4 起；不可用时退回 Edge / Chrome 窗口）

## 怎么安装和打开

| | macOS（Apple Silicon） | Windows（x64） |
|---|---|---|
| 下载 | GitHub → Actions → sentiment-monitor → 最近一次成功运行 → Artifacts 里的 `SentimentMonitor-macOS`（内含 `SentimentMonitor.dmg`） | 同一页面里的 `SentimentMonitor-Setup-Windows`（安装程序）或 `SentimentMonitor-Windows`（免安装文件夹） |
| 安装 | 打开 `SentimentMonitor.dmg`，把 `SentimentMonitor.app` 拖进「应用程序」 | 运行 `SentimentMonitor-Setup.exe`，装到 `%LOCALAPPDATA%\Programs\SentimentMonitor\`，不需要管理员权限；或解压免安装文件夹 |
| 首次打开 | 没有签名：右键 → 打开，或「系统设置 → 隐私与安全性 → 仍要打开」 | SmartScreen 提示时点「更多信息 → 仍要运行」 |
| 日常打开 | 「应用程序」或启动台里双击 | 开始菜单或桌面的「舆情监控」快捷方式；免安装版双击 `SentimentMonitor.exe` |
| 退出 | ⌘Q、菜单退出、关闭最后一个窗口，或页面右上角「退出」 | Alt+F4、关闭窗口，或页面右上角「退出」 |

v0.4 起 macOS 不再需要 Chrome；Windows 用系统的 WebView2（没有时改用 Edge）。详细的启停行为见 [使用指南](<01 使用指南.md>) 第 1 节。

## 几个目录不要混淆

| 目录 | 内容 | 位置 |
|---|---|---|
| 源码目录 | 本仓库的 `sentiment-monitor/` | GitHub 仓库 |
| 安装后的程序 | 打包好的程序文件（含文档和源码副本，只读） | macOS：`/Applications/SentimentMonitor.app`；Windows：你解压的文件夹 |
| 运行数据目录 | `monitor.db`（全部数据）、`monitor.log`（日志）、`browser-profile/`（应用窗口的浏览器配置） | macOS：`~/Library/Application Support/SentimentMonitor/`；Windows：`%APPDATA%\SentimentMonitor\` |
| 文档目录 | 本目录 `docs/` 和 `README.md` | 仓库里；也同步到 Obsidian 的 `Claude/舆情监控系统/` |

替换新版本时数据目录不动，监控对象、数据源、资讯和设置都会保留。
