# 舆情监控系统 v0.1

面向股票投资的舆情监控工具，也可以监控行业、公司、品牌、人物等任意关键词。后台是本机 Python 服务，界面是 HTML 页面，以独立应用窗口打开。

- **打开程序**：后台和页面同时启动。
- **关闭窗口**：后台自动退出，不留后台进程。
- **点页面右上角“退出”**：后台退出，窗口一起关闭。

只用 Python 标准库，不需要 `pip install` 任何依赖。数据保存在本机 SQLite 文件里，服务只监听 `127.0.0.1`，外部访问不到。

## 快速开始（Windows）

### 方式一：免安装 exe（推荐给不装 Python 的电脑）

1. 到 GitHub 仓库的 **Actions → sentiment-monitor**，打开最近一次成功的运行，在 **Artifacts** 里下载 `SentimentMonitor-Windows`。
2. 解压后双击 `SentimentMonitor.exe`。不会弹出黑色命令行窗口，应用窗口直接打开。
3. 关掉应用窗口，程序就退出了。

自己打包：

```bat
pip install pyinstaller
python packaging\build.py
```

生成的文件在 `dist\SentimentMonitor\`。

### 方式二：用源码运行（需要 Python 3.9 以上）

| 文件 | 作用 |
| --- | --- |
| `start-windows.bat` | 双击启动，不显示命令行窗口 |
| `start-windows-debug.bat` | 带命令行窗口启动，能看到实时日志，排查问题时用 |
| `start-mac-linux.sh` | macOS / Linux 下启动 |

安装 Python 时记得勾选 **Add python.exe to PATH**。

命令行参数：

```bash
python run.py                 # 启动并打开应用窗口
python run.py --demo          # 同时写入一批演示数据（标有“演示数据”）
python run.py --port 9000     # 指定端口（默认 8848，被占用时自动换一个）
python run.py --no-browser    # 只启动后台，不打开页面
python run.py --data-dir D:\monitor-data   # 指定数据目录
```

已经在运行时再次双击，不会启动第二个后台，只会再打开一个页面。

## 页面功能

| 页面 | 内容 |
| --- | --- |
| 总览 | 24 小时资讯量、利好/利空数量、情绪指数、风险信号；近 14 天每日资讯量（按情感堆叠）和情绪指数曲线；监控对象热度榜（含实时行情涨跌）；最新预警；来源分布 |
| 资讯流 | 按对象、情感、来源、时间、风险、关键词筛选；新资讯实时提示；每条资讯显示情感得分、命中的情感词、风险标签、关联对象；导出 CSV（Excel 可直接打开） |
| 监控对象 | 添加/编辑股票或关键词：名称、代码、市场、别名、排除词；点一行查看该对象近 30 天的趋势和最新资讯 |
| 数据源 | 启用/停用、抓取间隔、上次抓取状态和报错、立即抓取；添加数据源时可以先“测试”看抓取结果 |
| 预警中心 | 风险词预警、负面舆情预警、热度异动预警；页面右下角弹提示，可开桌面通知和提示音 |
| 设置 | 关窗口后是否退出、浏览器、网络代理、情感阈值、预警规则、红涨绿跌/绿涨红跌、数据保留天数 |

## 消息来源

| 数据源 | 方式 | 说明 |
| --- | --- | --- |
| 新浪财经滚动新闻 | 网站 JSON 接口 | 可选栏目：财经、股市、美股、科技 |
| 东方财富 7×24 快讯 | 网站 JSON 接口 | 全球财经快讯 |
| 财联社电报 | 网站 JSON 接口 | 7×24 电报 |
| 东方财富资讯搜索 | 网站 JSON 接口 | 按每个监控对象的名称搜索 |
| 必应新闻 | RSS | 按监控对象搜索，国内可直接访问 |
| Google 新闻 | RSS | 按监控对象搜索，需要在设置里填代理（默认关闭） |
| Yahoo Finance | RSS | 按股票代码订阅英文新闻，A 股和港股代码会自动转换 |
| 通用 RSS / Atom | RSS | 任意订阅地址。配合 [RSSHub](https://docs.rsshub.app/) 可以订阅雪球、微博、公众号等 |
| 行情（只用于显示涨跌） | 腾讯财经行情接口 | A 股、港股、美股 |

“快讯类”数据源先抓全量资讯，再用名称、别名、代码匹配监控对象；“搜索类”数据源对每个监控对象分别查询。抓取间隔和开关都在“数据源”页调整。

> **注意**：国内财经网站的接口都是网站页面自己在用的公开接口，不是官方开放 API，网站改版后可能失效。失效时“数据源”页会显示具体报错，其他数据源照常工作。请合理设置抓取间隔（快讯类 3–5 分钟、搜索类 15–60 分钟），并遵守各网站的使用条款。

## 情感分析和预警

- **情感打分**：使用金融领域中英文词典，考虑否定词（如“不减持”“否认造假”）和程度词（如“大幅”“小幅”），标题权重是摘要的 2 倍。得分范围 -1 到 1，界面上显示为 -100 到 100。每条资讯都会显示命中了哪些词，方便核对打分依据。
- **风险标签**：监管处罚、财务风险、股东减持、经营风险、法律诉讼、退市风险。
- **预警规则**（阈值在设置里调整）：
  - 命中风险词 → 红色预警；
  - 情感得分低于阈值（默认 -40）→ 黄色预警；
  - 某个对象近 1 小时资讯量达到前 23 小时平均值的 3 倍，且至少 5 条 → 热度异动。

词典法速度快、结果可解释，但读不懂反讽和复杂语境。后续可以换成大模型打分，见 `docs/ARCHITECTURE.md` 的“扩展”一节。

## 数据位置

| 系统 | 目录 |
| --- | --- |
| Windows | `%APPDATA%\SentimentMonitor\` |
| macOS | `~/Library/Application Support/SentimentMonitor/` |
| Linux | `~/.local/share/sentimentmonitor/` |

目录里有 `monitor.db`（全部数据）、`monitor.log`（运行日志）和 `browser-profile/`（应用窗口的浏览器配置）。备份时复制 `monitor.db` 即可。

## 常见问题

**关掉窗口后后台还在？**
确认“设置 → 关闭页面后自动退出后台”已打开。后台会在所有页面断开 10 秒后退出，这 10 秒是留给刷新页面用的。如果你想让它在后台持续采集，就把这个开关关掉，需要退出时在页面点“退出”。

**打开的是普通浏览器标签页，不是独立窗口？**
程序没找到 Edge 或 Chrome，改用了系统默认浏览器。这种情况下关掉标签页，后台同样会自动退出。

**某个数据源一直失败？**
在“数据源”页点“编辑 → 测试”查看具体报错。海外数据源（Google、Yahoo）需要在设置里填代理；国内接口报错通常是网站改版或访问太频繁。

**测试**

```bash
python -m unittest discover -s tests -v
```

测试全部离线运行，不访问外网。
