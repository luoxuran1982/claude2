# AI 短视频工厂

把开源项目 [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo)（MIT 许可，GitHub 约 13 万星）包成可以双击安装的桌面应用：**给一个主题 → 大模型写文案和搜索关键词 → 从 Pexels / Pixabay 等免费素材站下载视频片段拼接 → 配音 + 字幕 + 背景音乐 → 合成竖屏或横屏短视频**。

当前版本 **1.1.0**，内置上游 MoneyPrinterTurbo 1.3.8（commit `bbe7eb9`，2026-10-10）。macOS（Apple 芯片）和 Windows（x64）各有安装包，打开后是独立窗口。做这个项目的目的，是和本仓库根目录的「AI 知识视频工坊」（`studio/`）对比两种做视频的思路，见 [04 与 AI 知识视频工坊的对比](<docs/04 与AI知识视频工坊的对比.md>)。

**1.1.0（2026-10-15）新增**（用户看了 1.0.3 觉得知识卡片「能用但画面很 low」——没有「导演」，标题是按正则切出来的半截句子）：

- **知识讲解卡片（AI 导演）**：写完文案后多调用一次你配置的大模型设计分镜——每页完整短标题、版式（标题、要点、流程、对比、表格、代码、引言、数字、图表）、结构化数据、对应的原文句子；程序校验 JSON，不合格重试一次，再不行退回规则切分并写明原因；每页时间仍按配音和字幕对齐。原方案改名「**知识讲解卡片（规则切分）**」原样保留。
- **工坊主题**：「AI 知识视频工坊」`studio/visuals.py` 的深色主题和全部版式完整移植，AI 导演默认用它，规则切分也能选，原来的浅色配色保留。
- **知识讲解卡片 + AI 插图**：导演挑最多 3 页概念页，用「设置 → 素材来源设置」里的 OpenAI 兼容文生图生成插图作背景；没配置时提示并退回纯卡片。混合来源也能选用 AI 导演补齐。
- **「审片 / 分镜」顶层标签页**：生成完成后一次看完每一页（审片网格：缩略图、序号和版式名、口播，点一格成片跳到那一页；分镜详情：大图、口播原文和字数、起止时间、结构化数据）；生成页、任务管理里都有入口，库存视频来源显示每段素材的缩略帧和关键词。
- **「模型调用」顶层标签页**：每次大模型调用分块标明「程序发给模型的 / 模型的思考过程 / 模型返回的 / 程序怎么用它」，提示词里固定模板和程序填的变量用颜色区分，标出上一次输出进了下一次输入的位置；生成页只留链接。
- **字数控制方式**三档：让大模型自己数（严格）/ 程序检查（推荐，默认：偏差超过 ±15% 再请模型改写一次）/ 不控制。
- 每种视频来源的原理、要不要钥匙、花不花钱、和工坊的异同，见 [01 使用指南](<docs/01 使用指南.md>) 第 2.4 节。

**1.0.3（2026-10-15）新增和修复**（用户在 Windows 上实测 1.0.2 后的反馈）：

- **防重复提交、取消任务**：有任务在生成时「生成视频」变灰显示「生成中…」，连点无效，后台同时到达的几次只放行一个、同参数 90 秒内只保留一个；「任务管理」里生成中的任务有 ⏹「取消」（结束它的 FFmpeg，状态标「已取消」），取消后能删除；「生成中」但后台没在跑的残留任务标成「已中断」，可以删除。
- **「打开目录」真正修好**：1.0.2 在没有窗口的生成界面后台里调用 `os.startfile`，打开文件夹没反应；现在由拥有窗口的应用主进程打开（`/api/open-path`，只允许数据目录之内）。打不开时显示原因、完整路径和「复制路径」。
- **日志解读**：原始日志上方按「写文案 → 提取关键词 → 配音 → 字幕 → 找素材或画卡片 → 处理片段 → 拼接 → 最终渲染」讲清每步在做什么、为什么、正常要多久、常见出错原因，对应原始日志的行号。
- **大模型调用记录**：每次调用的步骤、服务和模型、完整提示词、完整原始输出、耗时、token 用量，存在任务目录的 `llm_calls.jsonl`，界面上可展开；不含 API Key。
- **目标时长**：30 / 60 / 90 / 120 秒或自定义，按语速换算成文案字数写进提示词，生成后对照目标和实际时长。
- **知识讲解卡片快速通道**：字幕直接画进讲解页，FFmpeg 一次合成画面、配音、背景音乐，只编码一次；自动用硬件编码器、失败回退 libx264。同一段约 47 秒竖屏文案（容器，4 核无显卡）：1.0.2 流程 205–235 秒 → 33–40 秒。库存视频流程不变。

**1.0.2（2026-10-14）新增和修复**：

- **新视频来源「知识讲解卡片」**（「视频来源」下拉里的「程序生成」组，免费、不联网、不需要素材钥匙）：讲「逻辑门」这类知识主题时，素材库只搜得到风景、动物，和内容不搭。新来源借用「AI 知识视频工坊」验证过的画法，不用 AI 画图，而是由程序按配音和字幕的时间把文案分成若干页，画出图文讲解页：标题、编号要点、对比两栏、流程箭头、关键数字、关键词高亮，按句子特征自动选版式；要点随配音逐条亮起，每页缓慢缩放或平移，三套配色可选。字幕、配音、背景音乐、拼接照常由上游完成。
- **「混合」来源**：先在 Pixabay / Pexels 搜素材，够用就全用素材；搜不到或不够时用知识卡片补齐，不再让任务失败。
- **「打开目录」在 Windows 上没反应**：改用系统自己的打开方式（Windows `os.startfile`、macOS `open`、Linux `xdg-open`），任务目录和缓存目录都修了。
- **声音和文案语言不一致时提醒**：中文文案选了 af-ZA、zu-ZA 这类非中文声音时，选声音时和点「生成视频」时都给出中文提示（这正是「No audio was received」的常见原因）。
- **配音失败按实际原因提示**：403（服务验证问题，请升级）、No audio received（声音和文案语言不一致，或代理节点被拒）、网络连不上，分别说明，不再一律把 403 写在第一条。
- **素材钥匙格式检查**：Pixabay 钥匙是「数字-25 位十六进制」，Pexels 是约 56 位字母数字；填错栏位时提示「这像是 Pixabay 的钥匙」。Pexels 返回非 JSON 或 401、Pixabay 返回 400 时给出中文原因。**Pexels 目前暂停发放新钥匙，推荐用 Pixabay。**
- **素材下载代理**：「设置 → 素材来源」里新增「素材下载代理（可选，如 http://127.0.0.1:7897）」，只有素材搜索和下载走这个代理，不用开系统代理。

1.0.1 修过的问题（Edge 配音 403，随包 edge-tts 升到 7.3.1、默认中文声音「晓晓」）见 [00 项目阅读入口](<docs/00 项目阅读入口.md>)。装新版覆盖旧版即可，设置和视频都保留。

## 安装与打开

安装包在仓库的 [Releases 页面](https://github.com/luoxuran1982/claude2/releases)（标签 `shortvideo-factory-v1.1.0`）。

| | macOS（Apple 芯片） | Windows（x64） |
| --- | --- | --- |
| 下载 | `ShortVideoFactory-1.1.0-macOS-arm64.dmg` | `ShortVideoFactory-Setup-1.1.0-x64.exe`（另有免安装 `ShortVideoFactory-1.1.0-windows-x64.zip`） |
| 安装 | 双击 `.dmg`，把「AI 短视频工厂.app」拖进「应用程序」 | 双击 Setup.exe，装到 `%LOCALAPPDATA%\Programs\ShortVideoFactory\`，不需要管理员权限，开始菜单和桌面有快捷方式 |
| 首次打开 | 没有 Apple 签名：在「应用程序」里右键 →「打开」→「打开」；仍被拦就到「系统设置 → 隐私与安全性」点「仍要打开」 | 没有代码签名：SmartScreen 提示时点「更多信息 → 仍要运行」 |
| 退出 | ⌘Q、菜单「退出」、程序坞右键「退出」、点红色按钮关窗口、顶栏「退出」 | 点 ×、Alt+F4、任务栏右键「关闭窗口」、顶栏「退出」 |
| 卸载 | 把 `.app` 拖进废纸篓 | 「设置 → 应用」或开始菜单里的卸载快捷方式 |
| 数据目录（卸载后保留） | `~/Library/Application Support/ShortVideoFactory/` | `%LOCALAPPDATA%\ShortVideoFactory\` |

关闭窗口或退出时，生成界面后台（Streamlit）、正在运行的 FFmpeg 等本应用启动的进程都会结束，端口释放；最小化只是隐藏，应用继续运行。安装包 macOS 约 430 MB、Windows 约 130 MB（自带 Python 运行时和视频处理组件），不需要另装 Python 或 FFmpeg。

## 第一次使用要准备的

1. **大模型 API Key**（写文案、生成搜索关键词）：顶部「设置」里选服务商（DeepSeek、通义千问、Kimi、智谱、OpenAI 兼容接口、本地 Ollama 等），填 Key 和模型名，点「测试连接」。自己写好文案的话可以不填。
2. **选视频来源**：
   - **知识讲解卡片**（「程序生成」组）：不需要任何素材钥匙，适合讲概念、原理、步骤、对比、数字的知识类主题（逻辑门、光合作用、利率怎么算）。「AI 导演」多用一次大模型、画面最好；「规则切分」完全不调用大模型画分镜；「+ AI 插图」还要配置 OpenAI 兼容文生图。
   - **Pixabay**（推荐的库存视频来源，免费）：登录 <https://pixabay.com/api/docs/>，页面里直接显示你的钥匙（「数字-25 位十六进制」），整段复制到「设置 → 素材来源 → Pixabay API Key」。适合情绪、生活、风景、美食、旅行这类实拍画面好看的主题。
   - **Pexels**：目前暂停发放新的 API 钥匙，新申请的钥匙可能用不了；已有能用的钥匙照常可用。
   - **混合**：先搜 Pixabay / Pexels 素材，不够时用知识卡片补齐。
   - 访问素材站需要代理时，在「设置 → 素材来源」底部填「素材下载代理」，例如 `http://127.0.0.1:7897`。
3. **配音声音**：默认中文「晓晓」（zh-CN-XiaoxiaoNeural）。换声音时选 zh-CN 开头的，和文案语言一致。
4. 可选：把你有权使用的背景音乐（mp3）放进数据目录的 `songs/`。上游自带的音乐来源不明，没有随包分发。

详细步骤见 [01 使用指南](<docs/01 使用指南.md>)。应用里所有 Key 只保存在你电脑上的 `config.toml`，不上传、不进仓库。

## 应用内有什么

- **视频生成**：上游 MoneyPrinterTurbo 的完整界面（中文），文案、素材、配音、字幕、背景音乐、合成都在这里；「视频来源」多了「程序生成」组（规则切分 / AI 导演 / AI 插图卡片、混合）；1.0.3 加了目标时长、日志解读，任务管理里能取消；1.1.0 加了字数控制方式。
- **审片 / 分镜**（1.1.0）：生成完成后逐页查看画面（网格总览、逐镜详情）。
- **模型调用**（1.1.0）：一个任务的每次大模型调用，原汁原味。
- **使用指南**：离线显示本 README、[UPSTREAM.md](UPSTREAM.md) 和 `docs/` 下全部文档；「源码」里逐个只读查看外壳和上游源码（带行号），可下载源码 zip。
- **运行状态**：本应用每个进程的职责、PID、内存（macOS RSS / Windows 工作集，MiB）和采样时间。
- **界面缩放**：顶栏右侧「−」、百分比下拉、「＋」、「100%」，70%–120% 每 5% 一档，作用于整个界面（包括生成界面），下次打开保留。

## 目录结构

```
shortvideo-factory/
  run.py                    源码运行入口（开发用）
  svf/                      外壳：启动器、本机服务与反向代理、进程管理、使用指南、运行状态、审片 / 分镜、模型调用、界面
  svf_ext/                  外壳扩展（在生成界面后台里运行）：知识讲解卡片（规则切分、AI 导演、工坊主题、AI 插图、分镜图）与快速通道、字数控制、防重复提交与取消、日志解读、大模型调用记录、目标时长、中文出错原因、钥匙检查、素材代理、打开目录
  upstream/                 上游 MoneyPrinterTurbo 源码（bbe7eb9，打了 9 处小补丁，见 UPSTREAM.md）
  fonts/                    随包的开源字体（思源黑体 Noto Sans SC Bold）和 OFL 许可证
  packaging/                打包脚本（PyInstaller + 随包 Python + NSIS / dmg）与 CI 冒烟测试
  tests/                    外壳单元测试、上游离线测试的筛选运行器、界面检查脚本
  docs/                     文档（同时是应用内「使用指南」的来源，同步到 Obsidian）
  requirements.txt          外壳依赖；requirements-runtime.txt 是生成界面后台的依赖（按上游锁定版本）
```

## 从源码运行（开发者）

```bash
cd shortvideo-factory
python3.11 -m venv .venv && . .venv/bin/activate      # Windows：.venv\Scripts\activate
pip install -r requirements.txt -r requirements-runtime.txt
python run.py              # 独立窗口（不可用时自动改用浏览器）
python run.py --browser    # 用默认浏览器打开
python -m unittest discover -s tests -v
python packaging/build.py  # 在哪个系统上运行就打出哪个系统的安装包（需要 pyinstaller pillow uv）
```
