## 这是什么

「AI 短视频工厂」是把开源项目 MoneyPrinterTurbo（MIT，GitHub 约 13 万星）包成的桌面应用。给一个主题，它让大模型写文案和英文搜索关键词，到 Pexels / Pixabay 等免费素材站下载视频片段拼起来，再配上 Edge TTS 等配音、自动字幕和背景音乐，合成竖屏（抖音、视频号）或横屏短视频。

做这个项目，是为了和本仓库自己做的「AI 知识视频工坊」比较两种思路：一个用网络素材拼接，一个在本机按模板画帧。对比结论和对比实验的步骤在 [04 与 AI 知识视频工坊的对比](<04 与AI知识视频工坊的对比.md>)。

## 1.0.1 更新了什么（2026-10-14）

1.0.0 在 Windows 上实际使用时，DeepSeek 写文案和关键词都成功，但配音失败：界面显示「failed to synthesize audio」，`webui.log` 里连着 3 次 `azure_tts_v1 ... failed, error: 403, message='Invalid response status'`，把声音从 zu-ZA-ThandoNeural 换成中文也一样。原因是微软 Edge 在线朗读接口改了验证方式，1.0.0 随包的 edge-tts 7.2.7（来自上游锁文件）被拒；edge-tts 7.3.0 起改用 Sec-MS-GEC v2 令牌。1.0.1：

- 随包 edge-tts 升到 **7.3.1**（依赖清单生成脚本加了「覆盖上游锁定版本」的机制，原因写在 `packaging/make_runtime_requirements.py`；7.3.1 的依赖锁文件里都满足，没有连带升级）。核对过上游的调用（`voice.azure_tts_v1`：`Communicate(boundary=...)`、`stream()`、`SubMaker.feed/get_srt`）在 7.3.1 下接口没变，不需要改上游代码。
- 默认配音声音改成中文「zh-CN-XiaoxiaoNeural」（晓晓）：新用户首次打开就选好；老用户配置里没有 voice_name 时补上，选过的声音不动。
- 配音失败时，界面红色提示后面补一段中文原因说明（403 多半是接口变更要升级、网络拦截、声音与文案语言不一致，以及怎样换配音引擎）。
- 详见 [01 使用指南](<01 使用指南.md>) 第 5 节「配音失败（403）」和 [UPSTREAM.md](<../UPSTREAM.md>)「依赖的版本」。

## 安装方法（摘要）

- **macOS**：从 Releases 下载 `ShortVideoFactory-1.0.1-macOS-arm64.dmg` → 双击 → 把「AI 短视频工厂.app」拖进「应用程序」→ 第一次在「应用程序」里右键 →「打开」。
- **Windows**：从 Releases 下载 `ShortVideoFactory-Setup-1.0.1-x64.exe` → 双击安装（不需要管理员）→ SmartScreen 提示时点「更多信息 → 仍要运行」→ 从开始菜单或桌面快捷方式打开。不想安装就下载 `ShortVideoFactory-1.0.1-windows-x64.zip`，解压后双击 `ShortVideoFactory.exe`。

Releases 页面：<https://github.com/luoxuran1982/claude2/releases>（标签 `shortvideo-factory-v1.0.1`，由主会话发布）。

## 源码、安装包、数据、文档分别是什么

| 东西 | 在哪 | 能做什么 | 不能做什么 |
| --- | --- | --- | --- |
| 安装包 | Releases 页面 | 安装后双击使用，自带 Python 运行时、FFmpeg、开源字体 | 不含 API Key、背景音乐；没有 Apple / 微软代码签名 |
| 源码 | 仓库 `shortvideo-factory/` | 阅读、修改、重新打包；`python run.py` 从源码运行 | 日常使用不必看 |
| 运行数据 | 上表「数据位置」 | 保存你的设置、Key、生成的视频、素材缓存、日志 | 不在安装目录；卸载、升级都不会删 |
| 文档 | 仓库 `shortvideo-factory/docs/`，Obsidian 里是 `Claude/AI 短视频工厂/`，应用里是「使用指南」 | 三处内容相同 | Obsidian 里的是镜像，要改请在仓库改 |
