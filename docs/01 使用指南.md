## 1. 怎样开始和结束

### 安装和首次打开

安装包由 GitHub Actions 构建：仓库 → Actions → build → 最新一次成功的运行 → Artifacts（需要登录 GitHub，保留 90 天）。

| | macOS（Apple 芯片，如 M4 Mac mini） | Windows（x64） |
|---|---|---|
| 下载 | `AIVideoStudio-macOS-AppleSilicon`，解压得到 `AIVideoStudio-<版本>-macOS-arm64.dmg` | `AIVideoStudio-Windows-x64`，解压得到 `AIVideoStudio-Setup-<版本>-x64.exe` 和免安装的 `AIVideoStudio-<版本>-windows-x64.zip` |
| 安装 | 双击 `.dmg`，把「AI 知识视频工坊.app」拖到旁边的「应用程序」 | 双击 `Setup.exe`，装到 `%LOCALAPPDATA%\Programs\AIVideoStudio\`，不需要管理员权限 |
| 首次打开 | 应用没有 Apple 开发者签名，第一次要在「应用程序」里**右键（或按住 Control 点按）→「打开」→ 再点「打开」**。仍被拦截时：「系统设置 → 隐私与安全性」，往下找到提示，点「仍要打开」 | 安装程序和应用都没有代码签名，SmartScreen 提示「Windows 已保护你的电脑」时点**「更多信息 → 仍要运行」**；杀毒软件拦截时把安装目录加入信任 |
| 以后打开 | 「应用程序」或启动台里双击「AI 知识视频工坊」 | 开始菜单或桌面的「AI 知识视频工坊」 |
| 卸载 | 把「AI 知识视频工坊.app」拖进废纸篓 | 「设置 → 应用」里卸载，或开始菜单里的「卸载AI 知识视频工坊」 |
| 数据（卸载后保留） | `~/Library/Application Support/AIVideoStudio/` | `%APPDATA%\AIVideoStudio\` |

免安装版（Windows zip）：解压到任意位置，双击 `AIVideoStudio.exe`。

打开后是一个**独立窗口**（Windows 用系统的 WebView2，macOS 用系统的 WKWebView），没有控制台窗口。不需要另装 Python 或 FFmpeg（FFmpeg 随包附带）。窗口建不起来时（例如 Windows 缺少 WebView2 运行时），程序会自动改用默认浏览器打开，原因写在数据目录的 `studio.log`。

从源码运行（开发者）：macOS 双击 `start-mac.command`，Windows 双击 `start-windows.bat`，或命令行 `python run.py`（默认独立窗口；`--browser` 用浏览器；`--no-browser` 只启动服务）。

### 首次准备

1. 「设置 → 文案模型」：选预设，填 API Key，点「测试连接」。不填也能用：创作页可以粘贴自己的稿子或导入分镜 JSON，零 token。
2. 「设置 → 配音」：默认用系统语音（macOS 婷婷、Windows 慧慧），点「试听」。云端 TTS 需要填接口和 Key。
3. 可选：把背景音乐放进音乐文件夹，把授权清晰的图片导入素材库。

需要网络的只有：文案模型、云端 TTS、edge-tts、Pexels 搜图。其余在本机完成。

### 结束和退出：各种操作的效果

本应用的后台就是主进程本身（一个进程，里面有窗口、HTTP 服务线程和任务线程）。渲染时会临时启动 FFmpeg 子进程，系统配音时会临时启动 `say`（macOS）/ PowerShell（Windows）子进程。

| 操作 | 结果 |
|---|---|
| macOS：菜单「退出」、⌘Q、程序坞右键「退出」 | 退出应用：取消正在跑的任务 → 结束本应用启动的子进程 → 停止后台服务、释放端口 → 进程退出 |
| macOS：点窗口左上角红色按钮；Windows：点右上角 ×、Alt+F4、任务栏右键「关闭窗口」 | 本应用只有一个窗口，关掉它就是关闭最后一个窗口，同上，退出应用并停止后台和子进程 |
| 点页面右上角「退出」 | 同上（窗口随之关闭） |
| 最小化、隐藏、切到其他应用 | 应用和后台继续运行，正在渲染的任务不中断 |
| 浏览器模式（窗口建不起来时自动改用）关闭浏览器标签页 | 后台在 3 分钟内没有收到页面的任何请求、且没有任务在跑时，自动退出。想立刻结束就点「退出」 |
| 从源码运行时在终端按 Ctrl+C 或关闭终端窗口 | 同「退出」 |

**崩溃或被强制结束时**（正常退出的收尾来不及执行）：
- Windows：子进程都放在一个「作业对象」里，主进程一消失，系统就结束它们。
- macOS：第一次启动子进程时，同时启动一个很小的守护进程（`/bin/sh` 循环），每 2 秒检查一次主进程是否还在；主进程不在了，就结束登记过的子进程，然后自己退出。它只监测本应用主进程，不碰别的程序。

已验证：退出流程、关窗口即退出、窗口失败回退浏览器，在 Linux 容器里用测试验证过（用模拟的窗口组件）；CI 在 macOS 和 Windows 上启动安装包里的程序，确认两个平台都能建起独立窗口（Windows 同时列出 WebView2 子进程），点「退出」后进程结束、端口释放。**待用户在自己电脑上验收**：真实的 ⌘Q、红色按钮、Alt+F4，以及之后在「活动监视器」/「任务管理器」里确认进程已结束。

## 2. 怎样完成主要任务

| 页面 | 用途 | 常用按钮 |
|---|---|---|
| 项目 | 列出全部项目 | 新建、打开、复制、删除（移到数据目录的 trash） |
| 创作 | 填主题、受众、时长、你的观点、参考资料 | 「保存并生成文案和分镜」（调用模型 1 次）、「不用缓存重新生成」、「按段落切分镜」（零 token）、「导入」分镜 JSON |
| 分镜 | 逐镜改口播和画面，右侧实时预览横/竖版 | 新增分镜、AI 改写单镜、换图 |
| 审片 | 风险提示、事实清单、读音检查、逐镜总览 | 刷新、再核查一遍（1 次模型调用）、点配图换图 |
| 导出 | 渲染成片 | 横版完整版、竖版精简版、竖版完整版；完成后可预览、打开文件夹 |
| 素材库 | 管理配图 | 导入图片、导入文件夹、改标签、删除 |
| 设置 | 模型、配音、渲染、配图参数 | 测试连接、试听、保存设置、打开数据/音乐/字体文件夹 |
| 运行状态 | 本应用进程与内存 | 刷新、每 3 秒自动刷新 |
| 使用指南 | 全部文档、源码、快速上手 | 文档 / 源码 / 快速上手 三个标签；「下载全部源码（zip）」 |

最常用的顺序：项目 → 新建 → 创作（填观点和资料）→ 生成 → 分镜（修改）→ 审片 → 导出。

结果在哪里：每次导出放在 `数据目录/projects/<项目ID>/exports/<时间>/`，含 MP4、SRT 字幕、口播稿、横竖两张封面、`发布信息.txt` 和项目快照。导出页的「打开文件夹」可以直接打开。

## 3. 数据从哪来、何时更新

| 数据 | 来源 | 何时更新 |
|---|---|---|
| 文案、分镜、事实清单 | 你填的观点和资料 + 文案模型（或你的稿子 / JSON） | 只在点「生成」「改写」「核查」时调用；相同请求命中本地缓存 `cache/llm/` |
| 配音 | 系统语音 / 云端 TTS / edge-tts | 渲染时逐句合成；同一句同一音色有缓存 `cache/tts/` |
| 画面 | 本机用 Pillow 按模板绘制 | 每次预览和渲染时 |
| 配图 | 素材库（本地）；可选 Pexels 搜图 | 生成分镜后自动匹配；手动换图时 |
| 用量和费用估算 | 模型返回的 token 数 × 设置里填的单价 | 每次调用后累计到项目 |
| 进程和内存 | 运行时读取操作系统 | 打开「运行状态」页时，每 3 秒一次 |

数据目录：macOS `~/Library/Application Support/AIVideoStudio/`，Windows `%APPDATA%\AIVideoStudio\`。API Key 存在其中的 `private/`。

费用为 0 有两种含义：命中缓存（确实没花钱），或没填单价（没算）。用量页的 token 数为准。

## 4. 结果如何理解

- **事实清单**：模型给出的把握度（高/中/低）只是提示，低把握度的一定要自己核对。核查结果不是权威来源。
- **风险提示**：本地关键词规则（投资承诺、医疗疗效、绝对化用语等），不是法律意见。
- **配图分数**：素材标签和英文画面描述的匹配度（0–1），低于及格线就改用文字卡，不硬配。
- **运行状态**：见第 7 节。
- **未实现或未验证**：Apple 开发者签名和 Windows 代码签名（所以首次打开有系统提示）；macOS 窗口的网页进程不在运行状态里列出（见第 7 节）；macOS / Windows 真机上的安装、退出与进程检查待用户验收。

## 5. 出了问题怎么办

| 现象 | 检查路径 |
|---|---|
| 双击没反应 / 被拦截 | macOS：右键 →「打开」，或「系统设置 → 隐私与安全性 → 仍要打开」。Windows：SmartScreen「更多信息 → 仍要运行」；杀毒软件拦截时把安装目录加入信任 |
| 打开的是浏览器而不是窗口 | 窗口组件没起来，程序已自动改用浏览器。看数据目录的 `studio.log` 里「窗口启动失败」后面的原因。Windows 多半是缺 WebView2 运行时：到微软官网下载「Microsoft Edge WebView2 Runtime」安装后重开 |
| 什么都没出现 | 看 `studio.log` 的最后几行；在「活动监视器」/「任务管理器」里结束残留的 `AIVideoStudio` 后再打开 |
| 页面提示「令牌无效」 | 浏览器模式下地址缺了 `?t=...`。退出后重新打开应用；每次启动令牌都不同 |
| 生成失败 | 设置 → 测试连接；检查 API Key、接口地址、余额、网络/代理 |
| 「模型输出被截断」 | 提示里会写这次最大输出多少、模型实际用了多少、其中思考占多少。思考型模型（如 deepseek-flash）先思考再写稿，思考也算在最大输出里。把「设置 → 最大输出 token」调大（默认 32000）；只按实际用量收费，填大不会多花钱。截断的结果不会进缓存，改完直接再点生成 |
| 「Invalid max_tokens value」 | 0.3.1 起不会再出现：最大输出填得比服务商上限还大时（DeepSeek 上限 393216），程序自动按上限请求，并在任务日志里注明 |
| 「等了 600 秒模型还没写完」 | 长稿加思考可能要几分钟。程序不会自动重试（重试会重复计费）。缩短目标时长，或稍后重新生成 |
| 配音失败 | 设置 → 试听。macOS 在「系统设置 → 辅助功能 → 朗读内容」下载中文语音；Windows 安装中文语音包；云端 TTS 检查 Key |
| 渲染失败「找不到 FFmpeg」 | 打包版自带；源码运行时 `pip install imageio-ffmpeg` 或在设置里填 ffmpeg 路径 |
| 中文显示成方框 | 把中文字体放进字体文件夹（设置 → 打开字体文件夹） |
| 退出后还有进程 | 打开「活动监视器」/「任务管理器」搜 `AIVideoStudio`、`ffmpeg`；正常情况下应已结束，如有残留请手动结束并把 `studio.log` 反馈过来 |

## 7. 当前进程与内存

位置：顶部导航「运行状态」。

每行是一个进程：职责、进程名、PID、内存（MiB）、采样时间。可能出现的行：

| 职责 | 什么时候出现 |
|---|---|
| 主进程：后台服务（127.0.0.1 HTTP）+ 应用窗口 | 一直在。后台服务是主进程里的线程，所以页面上写「无独立后台」 |
| FFmpeg 子进程（编码/转码） | 渲染、音频转码时 |
| 配音/工具子进程 | 系统语音合成时（macOS `say`，Windows PowerShell） |
| 守护进程（主进程崩溃后清理子进程） | macOS / Linux 上第一次启动子进程后 |
| 窗口子进程（WebView2） | Windows 窗口模式：WebView2 会启动几个 `msedgewebview2.exe`，作为本应用的子进程逐个列出 |

- 口径：macOS / Linux 是常驻内存 **RSS**，Windows 是**工作集（Working Set）**；单位 **MiB**（1 MiB = 1024² 字节）。
- 浏览器模式下浏览器是外部程序，不计入本应用合计。
- macOS 窗口的网页内容由系统的 WebKit 进程（`com.apple.WebKit.WebContent` 等）渲染，它们由系统启动、不是本应用的子进程，目前**没有列出**（未实现）；它们随窗口关闭由系统回收。
- 合计是各进程相加，进程间共享的内存可能被重复计算。
- 同一进程里的线程共享 PID，不单独列出。
- 子进程结束后立即从列表消失，不保留旧数值；读不到时显示「暂不可用」。
- Windows 任务管理器默认显示「专用工作集」，数值比这里的工作集小，属于口径差别。macOS 活动监视器的「内存」列也不是 RSS，对照时看「实际内存」更接近。

## 8. 怎样缩放界面

位置：顶部右侧、「退出」左边的一组控件：「−」、百分比下拉框、「＋」、「100%」。

- 档位：70%、75%、80%、85%、90%、95%、100%、105%、110%、115%、120%，共 11 档。
- 点下拉框直接选某一档；点「−」「＋」每次减/加 5 个百分点。下拉框和按钮始终显示同一个值。
- 到 70% 时「−」变灰，到 120% 时「＋」变灰。
- 点「100%」一键恢复默认。
- 缩放作用于整个界面（文字、按钮、表格、文档、源码）。切换页面、刷新、下次打开都保留（保存在数据目录的 `ui.json` 里，同时存一份在浏览器本地存储；每次启动端口不同，所以以 `ui.json` 为准）。
- 和系统显示缩放（如 Windows 125%、150%）叠加生效。
