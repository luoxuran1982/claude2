## 软件要解决什么问题

做知识类视频最费钱的是反复调用大模型和生图模型，最容易出错的是画面里的文字、数字和配图。本应用的做法：

- 大模型只负责「写」：标题、口播稿、分镜结构、事实清单，默认整条视频 1 次调用，结果缓存。
- 画面由程序按模板「画」：文字、表格、图表、代码都由 Pillow 绘制，不会画错字。
- 配音、字幕时间轴、合成全在本机：改一句只重配一句，渲染多少遍都不花 token。

## 进程关系

| 进程 | 谁启动 | 何时存在 | 退出时 |
|---|---|---|---|
| 主进程（`AIVideoStudio`，含窗口、HTTP 线程、任务线程） | 用户双击应用 / `python run.py` | 一直 | 关闭最后一个窗口、⌘Q / Alt+F4、页面「退出」、SIGTERM/SIGHUP/Ctrl+C，都走 `run.py` 末尾的收尾：取消任务 → 结束子进程 → 停 HTTP |
| WebView2 子进程（`msedgewebview2.exe`，仅 Windows） | 窗口组件 | 窗口打开时 | 随窗口关闭；运行状态页逐个列出 |
| WebKit 网页进程（仅 macOS） | 系统（launchd） | 窗口打开时 | 由系统回收；不是本应用子进程，运行状态页不列出 |
| FFmpeg 子进程 | `media.Runner.run` | 渲染、转码时 | 任务取消、退出时被结束；崩溃时由作业对象（Windows）或守护进程（macOS/Linux）结束 |
| 系统配音子进程 | `tts.py` 经 `Runner` | 合成配音时 | 同上 |
| 守护进程 `/bin/sh` | `procinfo._ensure_watchdog`（仅 macOS/Linux） | 第一次启动子进程后 | 正常退出时被结束；主进程消失后自行清理子进程并退出 |
| 浏览器（仅回退模式） | 系统默认浏览器 | 窗口建不起来时 | 外部程序，不随本应用退出；页面关闭 3 分钟后后台自动退出 |

## 调用链

**生成文案**：创作页「生成」→ `POST /api/projects/<id>/generate` → `jobs.JobManager.start` → `pipeline.generate` → `prompts` 拼提示词 → `llm.chat`（先查 `cache/llm`）→ `pipeline.apply_generation` → `images.assign` 自动配图 → `project.save`。

**渲染成片**：导出页「渲染」→ `POST /api/projects/<id>/render` → `pipeline.render`：① 逐句 `tts.TTS.synthesize`（查 `cache/tts`，经 FFmpeg 统一成 24kHz WAV）→ ② 按采样数算每句起止时间 → ③ `visuals` 逐帧画面 → ④ FFmpeg 编码 MP4、混背景音乐 → ⑤ 写 SRT、口播稿、封面、发布信息。

**使用指南**：`GET /api/guide/docs` 列出 `README.md` 和 `docs/` 下全部 `.md` → `GET /api/guide/doc?path=…` 取原文 → 前端 `md.js` 渲染。源码页 `GET /api/guide/sources` / `source?path=…` / `source.zip`，只按白名单（`guide.SOURCE_PATTERNS`）提供，不拼接用户给的路径。

**运行状态**：`GET /api/status/processes` → `procinfo.snapshot()`：主进程 + 登记的子进程 + （有 psutil 时）其他后代进程，逐个读 RSS / 工作集。

## 主要手写文件

| 文件 | 职责 |
|---|---|
| `run.py` | 入口：启动 HTTP 服务、打开窗口（失败写 `studio.log` 并改用浏览器）、统一的退出收尾 |
| `studio/server.py` | 路由表、令牌校验、静态文件和媒体文件 |
| `studio/pipeline.py` | 生成、改写、核查、审片、渲染的总流程 |
| `studio/llm.py`、`prompts.py` | 模型调用与缓存、提示词 |
| `studio/tts.py` | 各配音引擎 |
| `studio/visuals.py` | 画面模板（Pillow） |
| `studio/images.py` | 素材库与配图打分 |
| `studio/media.py` | FFmpeg 定位、可取消的子进程 `Runner`、WAV 工具 |
| `studio/guide.py` | 使用指南的文档与源码白名单 |
| `studio/procinfo.py` | 子进程登记、进程与内存采样、退出与崩溃清理 |
| `studio/web/app.js` | 前端全部逻辑（含缩放、运行状态、使用指南） |
| `studio/web/md.js` | 小型 Markdown 渲染器（随应用打包） |
| `packaging/build.py` | PyInstaller 打包成窗口程序，带上 `README.md`、`docs/` 和手写源码 `source/`；macOS 出 `.app` + `.dmg`，Windows 出 NSIS 安装程序 + 免安装 zip |
| `packaging/installer.nsi`、`make_icon.py`、`smoke.py` | Windows 安装程序脚本、生成图标、CI 冒烟测试 |

完整源码在应用「使用指南 → 源码」里逐个查看，或下载 zip。

## 打包后文件在哪里

安装后：macOS 是 `/Applications/AI 知识视频工坊.app`（数据文件在 `Contents/Resources/`），Windows 是 `%LOCALAPPDATA%\Programs\AIVideoStudio\`（数据文件在 `_internal\`）。

PyInstaller 打包后，Python 代码只有 `.pyc`。为了让安装版也能在应用里看源码和文档，`build.py` 额外放入：

- `README.md`、`docs/`：使用指南的文档
- `source/`：按白名单复制的手写源码（`.py`、`.html`、`.js`、`.css`、启动脚本、CI 配置）

构建结束时 `build.py` 会检查这些文件是否都在，缺一个就让构建失败。
