## 这是什么

AI 知识视频工坊把「主题 + 你的观点 + 参考资料」做成横版长视频和竖版短视频。大模型只写稿和分镜（默认整条视频调用 1 次）；配音、画面、字幕时间轴和合成都在本机完成。

- 当前版本：**0.2.0**（界面左上角显示版本号，源码在 `studio/__init__.py`）
- 平台：Windows、macOS（Apple Silicon），Linux 也能从源码运行
- 界面：本机 Python 服务（只监听 127.0.0.1）+ 网页界面，默认在浏览器里打开

## 怎么安装和打开

| | macOS | Windows |
|---|---|---|
| 当前能拿到的包 | GitHub Actions → build → Artifacts 里的 `AIVideoStudio-macOS`（免安装文件夹） | 同上，`AIVideoStudio-Windows` |
| 打开 | 解压后双击 `AIVideoStudio`；首次被拦截时右键 →「打开」，或「系统设置 → 隐私与安全性 → 仍要打开」 | 解压后双击 `AIVideoStudio.exe`；SmartScreen 提示时点「更多信息 → 仍要运行」 |
| 从源码运行 | 双击 `start-mac.command`（需要 Python 3.9+） | 双击 `start-windows.bat`（需要 Python 3.9+） |

**未实现**：交付要求里的 `.dmg`（内含 `.app`）和 `AIVideoStudio-Setup.exe` 安装程序、开始菜单快捷方式。现在只有免安装文件夹，打开后会有一个控制台窗口和一个浏览器页面。

详细步骤见 [使用指南](<01 使用指南.md>)。

## 几个目录不要混

| 目录 | 是什么 |
|---|---|
| 仓库根目录 `studio/`、`run.py`、`packaging/`、`tests/` | 源码 |
| `dist/AIVideoStudio/` | 打包产物（CI 构建，用户下载的就是它） |
| macOS `~/Library/Application Support/AIVideoStudio/`<br>Windows `%APPDATA%\AIVideoStudio\` | 运行数据：项目、素材库、缓存、设置、密钥。替换新版本不会丢 |
| `docs/` | 本文档目录，同时是应用内「使用指南」的来源，也会同步到 Obsidian |
