## 这是什么

AI 知识视频工坊把「主题 + 你的观点 + 参考资料」做成横版长视频和竖版短视频。大模型只写稿和分镜（默认整条视频调用 1 次）；配音、画面、字幕时间轴和合成都在本机完成。

- 当前版本：**0.3.0**（界面左上角显示版本号，源码在 `studio/__init__.py`）
- 平台：Windows、macOS（Apple Silicon），Linux 也能从源码运行
- 界面：独立窗口（Windows WebView2 / macOS WKWebView），后台是同一进程里的本机服务（只监听 127.0.0.1）；窗口建不起来时自动改用浏览器

## 怎么安装和打开

安装包在 GitHub → Actions → build → 最新一次成功的运行 → Artifacts（需要登录 GitHub）。

| | macOS（Apple 芯片） | Windows（x64） |
|---|---|---|
| 安装包 | `AIVideoStudio-<版本>-macOS-arm64.dmg`，里面是「AI 知识视频工坊.app」 | `AIVideoStudio-Setup-<版本>-x64.exe`（另附免安装 zip） |
| 安装位置 | 拖进「应用程序」：`/Applications/AI 知识视频工坊.app` | `%LOCALAPPDATA%\Programs\AIVideoStudio\`，不需要管理员权限 |
| 首次打开 | 右键 →「打开」→「打开」；或「系统设置 → 隐私与安全性 → 仍要打开」 | SmartScreen：「更多信息 → 仍要运行」 |
| 以后打开 | 「应用程序」或启动台里双击 | 开始菜单或桌面快捷方式 |
| 退出 | ⌘Q、菜单「退出」、关闭窗口 | 点 ×、Alt+F4 |

关闭窗口或退出应用时，后台服务和本应用启动的子进程一起结束。详细步骤和各种退出操作的区别见 [使用指南](<01 使用指南.md>)。

**未实现**：Apple 开发者签名和 Windows 代码签名（所以首次打开会有系统安全提示）。

## 几个目录不要混

| 目录 | 是什么 |
|---|---|
| 仓库根目录 `studio/`、`run.py`、`packaging/`、`tests/` | 源码 |
| `dist/`（`.dmg`、`Setup.exe`、`.zip`） | 打包产物（CI 构建，用户下载的就是它） |
| macOS `~/Library/Application Support/AIVideoStudio/`<br>Windows `%APPDATA%\AIVideoStudio\` | 运行数据：项目、素材库、缓存、设置、密钥。替换新版本不会丢 |
| `docs/` | 本文档目录，同时是应用内「使用指南」的来源，也会同步到 Obsidian |

## 当前状态

待用户验收：在自己的 Mac / Windows 电脑上下载安装包、安装、首次打开（含系统安全提示），试一次关窗口和 ⌘Q / Alt+F4，然后在「活动监视器」/「任务管理器」确认进程已结束。这些在云端容器里无法验证。
