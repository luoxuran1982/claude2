Qlib 量化研究台 1.0.1（基于微软开源项目 Qlib 0.9.8，MIT）。完整说明在应用内「使用指南」，或 [01 使用指南](<01 使用指南.md>)。

## macOS（Apple 芯片）

1. 打开 `QlibStudio-1.0.1-macOS-arm64.dmg`，把「Qlib 量化研究台」拖进「应用程序」。
2. 第一次打开：在「应用程序」里**右键「Qlib 量化研究台」→「打开」**→ 再点「打开」。（应用没有 Apple 签名；也可以到「系统设置 → 隐私与安全性」点「仍要打开」。）
3. 以后在「应用程序」或启动台里直接打开。
4. 退出：关闭窗口、⌘Q 或界面右上角「退出」，正在运行的任务和工作进程全部结束。
5. 卸载：把应用拖进废纸篓；数据在 `~/Library/Application Support/QlibStudio/`，需要时手动删除。

## Windows（x64）

1. 双击 `QlibStudio-Setup-1.0.1-x64.exe`。SmartScreen 提示时点「更多信息 → 仍要运行」。
2. 按提示安装（装到 `%LOCALAPPDATA%\Programs\QlibStudio\`，不需要管理员权限），开始菜单和桌面会有「Qlib 量化研究台」。
3. 免安装：解压 `QlibStudio-1.0.1-windows-x64.zip`，双击 `QlibStudio\QlibStudio.exe`。
4. 退出：关闭窗口（×）、Alt+F4 或界面右上角「退出」，正在运行的任务和工作进程全部结束。
5. 卸载：「设置 → 应用」或开始菜单「卸载 Qlib 量化研究台」；数据在 `%LOCALAPPDATA%\QlibStudio\`，卸载后保留。

## 用之前要知道

- 打开后先在「数据」页点「生成演示数据」，再到「实验」页「运行实验」，几分钟内就能看到完整报告（演示数据是模拟的，不是真实行情）。
- 真实数据：导入自己的通达信 / CSV 日线；或打开富途 / moomoo OpenD 并登录后下载日 K（有按账户的额度）；或下载社区 A 股数据集（约 570 MB，需要能访问 GitHub）。
- 深度模型（LSTM、Transformer 等）需要 PyTorch，安装包不带。
- 仅供学习研究，不构成投资建议。
