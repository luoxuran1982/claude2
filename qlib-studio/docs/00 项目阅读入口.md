Qlib 量化研究台是微软开源量化平台 **Qlib**（<https://github.com/microsoft/qlib>，MIT）的全中文桌面版。Qlib 是一个 Python 库：
把 A 股日线存成它自己的二进制格式，用表达式引擎算 Alpha158 / Alpha360 因子，训练 LightGBM 等模型预测下一期收益，
再按预测做组合回测。它没有界面，平常要写 YAML 配置、敲 `qrun` 命令。研究台把这一套装进 macOS / Windows 应用窗口，
不用命令行、不用装 Python；还补上了数据导入（通达信、CSV、富途 / moomoo OpenD、社区 A 股数据集）、数据质量检查和图表报告。

引入它的目的是和用户自己的「**QuantLab 量化学习实验室**」对比：两边思路一样（因子 → 模型 → 滚动训练 → 回测），
实现完全不同。对比结论、互相借鉴的清单和「同数据同区间」的对比步骤见第 04 篇。

## 怎么安装和打开

| | macOS（Apple Silicon） | Windows（x64） |
| --- | --- | --- |
| 下载 | Releases 页面的 `QlibStudio-1.0.0-macOS-arm64.dmg` | `QlibStudio-Setup-1.0.0-x64.exe`（或免安装 zip） |
| 安装 | 打开 dmg，把「Qlib 量化研究台」拖进「应用程序」 | 双击安装程序，装到 `%LOCALAPPDATA%\Programs\QlibStudio\`，不需要管理员权限 |
| 首次打开 | 没有签名：在「应用程序」里右键 →「打开」，或「系统设置 → 隐私与安全性」点「仍要打开」 | SmartScreen 提示时点「更多信息 → 仍要运行」 |
| 以后打开 | 「应用程序」或启动台里的「Qlib 量化研究台」 | 开始菜单或桌面的「Qlib 量化研究台」 |
| 退出 | 关闭窗口（红色按钮）、⌘Q、界面右上角「退出」 | 关闭窗口（×）、Alt+F4、界面右上角「退出」 |

完整说明（首次准备、关窗与最小化的区别、数据位置、故障处理）见 [01 使用指南](<01 使用指南.md>) 第 1 节；只想装上用，看 [安装说明](<安装说明.md>)。

## 四样东西不要混

| 东西 | 在哪 | 能做什么 |
| --- | --- | --- |
| 源码目录 | 仓库 `qlib-studio/`（外壳 `qlibstudio/`、上游 `upstream/`、文档 `docs/`、打包 `packaging/`、测试 `tests/`） | 阅读、修改、重建；有 Python 3.12 时可 `python run.py` 直接运行 |
| 安装包 | Releases 页面的 `.dmg` / `Setup.exe` / 免安装 zip | 安装后日常使用；包里附带全部文档和源码（只读） |
| 运行数据目录 | macOS `~/Library/Application Support/QlibStudio/`，Windows `%LOCALAPPDATA%\QlibStudio\` | 你的数据集（Qlib 格式）、富途缓存、实验结果、设置；换新版本、卸载都保留 |
| 文档 | 仓库 `qlib-studio/docs/`，同步到 Obsidian 的 `Claude/Qlib 量化研究台/` | 与应用内「使用指南」同一份 |
