## 1. 怎样开始和结束

### 安装和首次打开

| | macOS（Apple 芯片，M1–M4） | Windows 10 / 11（x64） |
| --- | --- | --- |
| 下载 | Releases 页面的 `QlibStudio-1.0.0-macOS-arm64.dmg`（约 300 MB 以内） | `QlibStudio-Setup-1.0.0-x64.exe`；不想安装就下 `QlibStudio-1.0.0-windows-x64.zip` |
| 安装 | 双击 dmg，把「Qlib 量化研究台」拖到「Applications / 应用程序」 | 双击安装程序 → 下一步。装在 `%LOCALAPPDATA%\Programs\QlibStudio\`，**不需要管理员权限**；开始菜单和桌面各有一个快捷方式 |
| 第一次打开 | 应用没有 Apple 签名。在「应用程序」里**右键「Qlib 量化研究台」→「打开」→「打开」**；或先双击一次，再到「系统设置 → 隐私与安全性」底部点「仍要打开」 | SmartScreen 可能提示「已保护你的电脑」：点「更多信息」→「仍要运行」。杀毒软件拦截时把安装目录加入信任 |
| 窗口组件 | 系统自带 WKWebView，不用装 | 用系统的 WebView2（Windows 11 自带；Windows 10 没有时会自动改用默认浏览器打开，功能相同） |
| 卸载 | 把 `.app` 拖进废纸篓 | 「设置 → 应用」里卸载，或开始菜单「卸载 Qlib 量化研究台」 |
| 卸载后数据 | `~/Library/Application Support/QlibStudio/` 保留，要彻底清除就手动删 | `%LOCALAPPDATA%\QlibStudio\` 保留 |

日常使用不需要开终端，也不需要装 Python。第一次打开大约 5–15 秒（解压运行库），之后会快一些。

### 首次准备

- **没有任何外部服务也能用**：在「数据」页点「生成演示数据」，再到「实验」页点「运行实验」，就能看到完整报告。演示数据是模拟的 A 股，不是真实行情。
- 想用真实数据，有三条路（详见第 3 节）：导入自己的通达信 / CSV 日线；连富途 / moomoo OpenD 下载；下载社区 A 股数据集（约 570 MB）。
- 富途 / moomoo OpenD 是可选的外部程序，要你自己下载、登录、开着（第 3 节「富途 / moomoo OpenD」）。本应用只连本机 `127.0.0.1`。

### 打开后发生什么

打开应用 = 启动一个主进程：它在本机 `127.0.0.1` 的一个随机端口上起一个只给自己用的网页服务，并打开应用窗口显示界面。
**没有常驻的后台服务**。只有在你点「生成 / 导入 / 下载 / 运行实验」时，才另起一个**工作进程**去干活（读数据、算因子、训练、回测），
干完工作进程就退出，内存全部还给系统。同一时间只运行一个任务，进度显示在顶部状态条。

### 关闭、退出和最小化

| 操作 | macOS | Windows | 结果 |
| --- | --- | --- | --- |
| 关闭最后一个窗口 | 红色关闭按钮 | 右上角 × | **退出应用**：结束正在运行的工作进程（任务作废，不保存半成品）→ 停本机服务、释放端口 |
| 退出 | ⌘Q、菜单「退出」、程序坞右键「退出」 | Alt+F4、任务栏右键「关闭窗口」 | 同上 |
| 界面右上角「退出」 | ✓ | ✓ | 同上；有任务在跑时先问你确认 |
| 最小化 / 隐藏 / 切到别的应用 | 黄色按钮、⌘H | 最小化按钮 | **应用和正在运行的任务继续运行**，切回来看进度 |

只有一个窗口，所以「关窗」就是「退出」。没有托盘常驻，关掉以后不会在后台继续算。
如果应用崩溃或被强制结束（活动监视器 / 任务管理器里结束），正在运行的工作进程每 2 秒检查一次主进程，发现主进程不在了会在 2 秒内自己退出，不会长期残留。
已经保存的数据集、实验结果、设置不受退出影响；只有「正在运行」的那个任务会作废，下次重新点一次即可。

### 实验的各个选项

| 选项 | 含义 | 默认 |
| --- | --- | --- |
| 数据集 | 「数据」页里的一个数据集 | 上次用的 |
| 股票池 | 数据集里有的股票池：全部股票、沪深主板、创业板、科创板、北交所；社区数据集另有沪深 300、中证 500 等成分股（Qlib 的 `instruments/*.txt`） | 全部股票（有沪深 300 时选它） |
| 因子集 | **Alpha158**：158 个量价因子（9 个 K 线形态、4 个价格、29 种滚动算子 × 5/10/20/30/60 日窗口）；**Alpha360**：过去 60 天的开、高、低、收、均价、成交量各除以当天收盘价/成交量，共 360 列原始序列 | Alpha158 |
| 模型 | LightGBM、XGBoost、CatBoost（梯度提升树）、线性 OLS、线性 Ridge。参数取自上游 `examples/benchmarks` 的 Alpha158 配置 | LightGBM |
| 深度模型 | LSTM、GRU、ALSTM、Transformer、TRA 等需要 PyTorch（约 1 GB），**安装包默认不带**，下拉框里显示为灰色。从源码运行并 `pip install torch` 后可用上游 `qrun` 命令跑 | 不可选 |
| 训练 / 验证 / 测试 | 训练集拟合模型；验证集用于早停（梯度提升树看验证集损失停止加树）；测试集是样本外，报告里的所有数字都只来自测试区间。三段要按顺序、不重叠 | 去掉开头 60 个交易日后按 6:2:2 |
| 滚动训练 | 打勾后，测试期每隔 N 个交易日重新训练一次，每段只用它之前的数据训练（上游 `RollingGen` 的切分思路）。验证窗口长度不变、跟着往后滑；训练窗口可选「起点固定、越来越长」（上游默认 ROLL_EX）或「长度固定、往后滑」（ROLL_SD） | 不打勾；N = 63，扩展窗口 |
| 持仓股票数 topk / 每天最多换出 n_drop | 上游 TopkDropout 策略：每天卖出持仓里预测最差的最多 n_drop 只，买入没持有的预测最好的，保持 topk 只 | 20 / 2 |
| 预测周期 | 标签 = 未来 N 天的收益（成交价到成交价）。Qlib 默认 1 天 | 1 |
| 成交价 | 当日收盘价（Qlib 默认）或当日开盘价（接近 QuantLab 的 T+1 开盘成交）。t 日收盘后算出的预测，在 t+1 日按这个价格成交 | 收盘价 |
| 涨跌停规则 | 按板块（主板 10%、ST 5%、创业板注册制后和科创板 20%、北交所 30%）；或上游默认（±9.5% 不分板块）；或不限制（只排除停牌） | 按板块 |
| 基准 | 自动（数据里有指数就用指数，否则股票池等权）、股票池等权、某个指数 | 自动 |
| 初始资金、费率 | 买入 0.05%、卖出 0.15%（含印花税）、每笔最低 5 元（上游 A 股示例的口径） | 100 万元 |

点「运行实验」后的步骤（进度条下面会逐条显示）：初始化 Qlib → 计算因子 → 训练（滚动时逐段）→ 计算 IC → 回测 → 整理结果。
「取消」会直接结束工作进程，这次实验不保存。运行出错时进度区显示中文原因，「查看日志」里有上游的完整输出。

### 结果在哪

- 界面：「报告」页；「实验记录」表里的年化收益、超额、最大回撤、夏普、RankIC 都是测试区间的数。
- 文件：数据目录下 `runs/<编号>/`：`result.json`（全部指标和曲线）、`positions.json`（每日持仓）、`trades.json`（成交明细）、
  `pred.csv`（每天每只股票的预测分数）、`export.json`（交换格式，给对比用）、`config.json`（这次的全部设置）。
- 导出：报告页「导出对比文件」（交换格式 JSON）、「导出成交 CSV」（Excel 可直接打开，UTF-8 带 BOM）。窗口模式下弹出保存对话框；浏览器模式下直接下载。

## 3. 数据从哪来、何时更新

所有来源最后都变成同一种东西：数据目录 `datasets/<编号>/` 下的一个 **Qlib 格式数据目录**
（`calendars/day.txt` 交易日历、`instruments/*.txt` 股票池、`features/<代码>/<字段>.day.bin` 二进制数据），
由上游 `scripts/dump_bin.py` 写出。价格口径和 Qlib 自带的 A 股数据一致：

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| `$open $high $low $close $vwap` | **复权价** = 不复权价 × 复权因子 | 元 |
| `$volume` | 不复权成交量 ÷ 复权因子 | 股 |
| `$amount` | 成交额 | 元 |
| `$factor` | 复权因子（回测用它把复权数量换回真实股数，凑整到 100 股一手） | — |
| `$change` | 复权收盘相对上一个有成交日的涨跌幅 | 小数 |
| `$limit_rate` | 当天涨跌停幅度（按板块和 ST） | 小数 |

**停牌**：成交量为 0 的行不写入，Qlib 里那一天就是空值，回测时不能买卖。**缺失、零、失败的区别**：
缺失 = 上市区间内某个交易日没有数据（停牌或数据源漏了，两者分不开，统一叫「缺失/停牌」）；零成交 = 有价格但成交量为 0（导入时已当停牌处理）；
失败 = 任务没跑成，原来的数据不受影响。

### 演示数据

和 QuantLab 用同一个生成器（`qlibstudio/data/demo.py` 原样复制自 QuantLab）：几百只模拟股票 + 一只模拟指数，
放了短期反转、中期动量、放量反转、低波动溢价几个弱规律，也有涨跌停、停牌、晚上市、退市和送转除权。**不是真实行情**，报告里会标「演示数据」。

### 通达信 / CSV（自己的数据怎么导）

1. 「数据 → 通达信 / CSV」，在输入框里填路径（每行一个），或点「选择文件夹… / 选择文件…」（窗口模式）。
2. 可以填：
   - 通达信目录：macOS 上一般是通达信安装目录里的 `vipdoc`，Windows 上如 `C:\new_tdx\vipdoc`。会读 `sh/lday`、`sz/lday`、`bj/lday` 下的 `.day` 日线，跳过分钟线目录。`.day` 是**不复权**价格。
   - 通达信「数据导出」的 txt（首行「600000 浦发银行 日线 前复权」那种）。
   - CSV / TSV / Excel / Parquet：列名中英文都能认（日期、开盘、最高、最低、收盘、成交量、成交额，可选代码、名称、复权因子 `adj_factor`）；一个文件可以带「代码」列放多只股票；Tushare 的单位（手、千元）自动换算；分钟线自动聚合成日线。
3. 选「复权方式」：
   - 自动（推荐）：文件里有复权因子列就用；文件名或表头标明「前复权 / 后复权」的当作已复权；其余按不复权处理，**自动估算除权日**（开盘相对前收的跳空超出涨跌停幅度 2% 以上视为除权，假设除权日隔夜收益为 0；小额现金分红识别不了，会留下很小的偏差）。
   - 全部按不复权 / 全部当作已复权：自动判断不对时手动指定。已复权数据的因子记为 1，回测时一手 100 股按复权价近似。
4. 点「导入并转成 Qlib 格式」。读取逻辑和 QuantLab 完全相同（`readers.py`、`adjust.py`、`market.py` 原样复制），所以同一份文件两边读出来的数据一致。

### 富途 / moomoo OpenD

OpenD 是富途官方的行情网关程序，装在你自己电脑上，本应用通过它下载 A 股日 K。

**怎么开**

1. 到富途官网（富途牛牛用户）或 moomoo 官网（moomoo 用户）的「OpenAPI」页面下载 **OpenD**（有 macOS 和 Windows 版，图形界面版最简单）。
2. 打开 OpenD，用你的富途 / moomoo 账号登录。登录后 OpenD 窗口里能看到「API 端口」，默认 **11111**，监听地址保持 `127.0.0.1`。
3. 回到本应用「数据 → 富途 / moomoo OpenD」，端口填一样的（默认 11111），点「**测试连接 · 查询额度**」。连上后显示历史 K 线额度。
4. 填股票代码（`600000, 000001, 300750` 或 `600000.SH`、`sz000001` 都行，逗号、空格、换行分隔），选开始、结束日期，点「下载并生成数据集」。

**额度说明**：OpenD 对历史 K 线有按账户的额度——**最近 30 天内请求过的「不同股票」数量**有上限（随账户资产和交易情况变化，常见 100 / 300 / 1000 / 2000 只，以 OpenD 返回为准）。
30 天内重复请求同一只股票不额外占用。本应用的做法：

- 下载前先查额度；这次要**新**请求的股票数超过剩余额度时直接停下并说明，不会请求到一半才失败。
- 每只股票下载后存进本地缓存 `futu-cache/<代码>.csv`（不复权价 + 复权因子），`index.json` 记录已覆盖的日期区间。
  **再次下载只请求缓存没覆盖的日期**；完全覆盖的股票根本不连 OpenD（界面显示「缓存命中（没请求）」）。
- 每只请求两次：不复权和后复权，复权因子 = 后复权收盘 ÷ 不复权收盘。后复权以上市首日为基准，老数据不会因为新的分红送转而变，所以可以增量补。
- 「本地缓存」折叠区列出每只缓存的代码、覆盖日期、行数和更新时间。

**限制**：北交所股票 OpenD 不提供，请用通达信或 CSV。A 股行情权限、能否请求 A 股历史 K 线取决于你的账户和 OpenD 行情权限，以 OpenD 返回为准。
连不上、没权限、额度不足、代码无效时，界面会给出中文原因（第 5 节）。

### 社区 A 股数据集（chenditc/investment_data）

Qlib 官方的 A 股数据集目前暂停下载；上游 README 推荐用社区维护的 **chenditc/investment_data**：作者每天从多个公开来源交叉校验后，
在 GitHub Releases 发布 Qlib 格式的 `qlib_bin.tar.gz`（约 570 MB，解压后约 2–3 GB，含沪深 A 股日线、指数和沪深 300 / 中证 500 等成分股，包括已退市股票）。

1. 「数据 → 社区 A 股数据集」→「下载最新一期并导入」。显示下载速度和进度；**中断后再点一次会从断点续传**。
2. 下载完自动解压、生成股票池、抽查 400 只做质量检查。默认导入后删除压缩包（省 570 MB）。
3. 国内网络访问 GitHub 下载可能很慢或失败：可以开代理，或在浏览器里打开 Releases 页面手动下载 `qlib_bin.tar.gz`，再用「从本地文件导入」。
4. 需要的磁盘空间约为压缩包的 5 倍；不够时下载前就会提示。

### 何时更新

本应用**不会自动更新任何数据**。每次「生成 / 导入 / 下载」都会新建一个数据集（不覆盖旧的），需要新数据就再点一次：
富途只补缓存缺的日期；社区数据集每次下载最新一期；通达信目录先在通达信里「盘后数据下载」更新，再导入一次。旧数据集不用了可以删除。

### 数据质量检查

每个数据集导入后自动检查，结论显示在数据集卡片上（良好 / 需注意 / 有错误），点「质量检查」看明细：

| 检查项 | 口径 |
| --- | --- |
| 缺失/停牌 | 上市区间（第一天到最后一天）内收盘价为空的交易日数 |
| 零成交天数 | 有价格但成交量为 0 |
| 长停牌 | 连续缺失超过 20 个交易日的片段 |
| 疑似未复权（复权提示） | 复权因子从不变化，但出现超出涨跌停幅度 3% 以上的收盘跳空——很可能是不复权数据里的除权日，会污染收益和因子 |
| 有复权因子 | 复权因子在变化（已处理除权） |
| 数据中断 | 最后一天早于整个数据集最后一天 20 个交易日以上（退市、改代码或没更新） |

社区数据集股票多，只抽查 400 只（界面注明「抽查」）。另外列出导入时每只股票用了哪种复权方式。

## 4. 结果如何理解

### 报告页的数字

| 指标 | 怎么算 | 读法 |
| --- | --- | --- |
| 累计收益、年化收益 | 账户净值（已扣费用）÷ 初始资金；年化按复利、一年 244 个交易日 | 只来自测试区间 |
| 基准年化、年化超额 | 基准净值的年化；组合年化 − 基准年化 | 基准见报告副标题 |
| 最大回撤、夏普 | 净值从高点回落的最大幅度；日收益均值 ÷ 标准差 × √244 | |
| 超额年化（Qlib 口径）、信息比率（Qlib） | 上游 `risk_analysis`：超额 =（组合收益 − 基准收益 − 费用）**按日相加**，年化 = 日均 × 238 | 和 Qlib 官方基准表、上游 `qrun` 输出可以直接比；和上面的复利口径数值不同是正常的 |
| IC / RankIC | 每天预测分数与下一期收益的皮尔逊 / 斯皮尔曼相关（上游 `calc_ic`）；ICIR = 均值 ÷ 标准差 | A 股日频 RankIC 在 0.03–0.06 已经不错；接近 0 说明没学到东西 |
| 分层收益 | 每天按预测分 5 组，每组下一期平均收益；累计曲线只取不重叠的持有期 | 第 5 组（预测最高）应该最好、单调递增最理想；不含费用和涨跌停 |
| 日均换手 | 上游报告的 turnover | 换手越高费用越多 |
| 持仓 | 每天收盘后的持仓：市值、权重、已持有天数 | |
| 交易明细 | 每笔成交：方向、**真实股数**（100 股整数倍）、不复权成交价、成交额、费用 | 买不进（涨停、停牌）的不会出现 |
| 训练 | 每段训练 / 验证 / 测试区间、预测条数、最佳轮数、训练损失曲线、因子重要性（LightGBM） | 最佳轮数很小说明验证集上很快就不再改善 |

### 适用范围和已知限制

- 回测是**模拟**：按上游 Exchange 的规则成交（涨跌停买不进 / 卖不出、停牌不能交易、一手 100 股、费用），不模拟冲击成本、盘口深度和成交量上限；收盘价成交意味着假设你能在收盘前按收盘价下单。
- 演示数据是模拟的，结果只说明流程跑通，不代表任何真实策略的表现。
- ST 状态按导入时的名称判断（只知道当前名称，属近似）；社区数据集没有名称，不区分 ST。
- 停牌和数据缺失分不开（见第 3 节）。
- 没有实现：深度模型（需 PyTorch）、分钟线、实盘下单、自定义因子表达式编辑器、超参数搜索。
- 还没在真实环境验证：连真实 OpenD 下载、下载完整社区数据集后在真实数据上跑实验（容器里只用模拟接口和缩小的夹具测过）。

## 5. 出了问题怎么办

| 现象 | 原因和处理 |
| --- | --- |
| macOS 提示「无法打开，因为无法验证开发者」 | 应用没签名。右键 →「打开」，或「系统设置 → 隐私与安全性 → 仍要打开」 |
| Windows SmartScreen / 杀毒软件拦截 | 点「更多信息 → 仍要运行」；杀毒软件把 `%LOCALAPPDATA%\Programs\QlibStudio\` 加入信任。打包程序在第一次运行时会解压很多文件，部分杀软会误报 |
| 打开后是浏览器而不是独立窗口 | 窗口组件不可用（Windows 10 缺 WebView2 等）时的自动退路，功能相同；关掉浏览器页面 3 分钟后应用自动退出。装上 WebView2 Runtime 即可用窗口 |
| 「连不上富途 OpenD（127.0.0.1:11111）：端口没有程序在监听」 | OpenD 没开或没登录，或者 OpenD 里的 API 端口不是 11111（把这里的端口改成一样的） |
| 「连接富途 OpenD 超时」 | OpenD 卡住或被防火墙拦截；重启 OpenD |
| 「没有这个市场的行情权限」 | 账户没有 A 股行情权限，在富途 / moomoo App 里确认 |
| 「历史 K 线额度不足」/「额度只剩 N 只」 | 30 天内请求过的不同股票数到上限了；减少股票数，或等额度释放。已缓存的股票不占额度 |
| 「北交所股票富途 OpenD 不提供 A 股行情」 | 用通达信或 CSV 导入北交所股票 |
| 社区数据集「连接超时 / 解析不了域名 / 证书校验失败」 | 网络访问不了 GitHub。重试会断点续传；或开代理；或浏览器下载后「从本地文件导入」。公司网络拦截 HTTPS 时会出现证书错误 |
| 「下载地址不存在（HTTP 404）」 | 作者改了发布文件名，到 Releases 页面看最新一期 |
| 「压缩包损坏或不是 tar.gz」 | 下载不完整；删掉数据目录 `downloads/` 里的文件重新下载 |
| 「没有读到任何日线数据」 | 路径不对，或文件格式认不出。看提示里列出的读取问题；CSV 至少要有日期和收盘两列 |
| 数据集质量「需注意：疑似未复权」 | 不复权数据里有除权跳空没处理。重新导入，复权方式选「全部按不复权处理」，或换带复权因子的数据 |
| 实验报「数据只有 N 个交易日，至少要 300 个」 | 数据太短；Alpha158 要 60 天窗口，训练、验证、测试各要一段 |
| 实验报「三个区间要按 训练 → 验证 → 测试 的顺序排列」 | 检查日期，或点「按 6 : 2 : 2 自动填」 |
| 实验报「数据集里没有股票池 xxx」 | 换一个股票池（下拉框只列数据集里有的） |
| 实验失败「内部错误：…」 | 点「查看日志」看上游的完整报错；「运行状态 → 任务记录」里也有每个任务的日志 |
| 实验很慢 | 股票多、区间长、开了滚动训练都会慢。先用小股票池和短区间试；CatBoost 比 LightGBM 慢 |
| 界面显示「连接本机服务失败」 | 应用已退出或崩溃；重新打开。日志在数据目录的 `qlibstudio.log` |
| 想找数据和日志 | 「运行状态 → 打开数据目录」；macOS `~/Library/Application Support/QlibStudio/`，Windows `%LOCALAPPDATA%\QlibStudio\` |

## 6. 软件框架、系统架构与源码

研究台要解决的问题：Qlib 很强但只有 Python 接口和命令行，A 股数据要自己准备，结果要自己画图；
研究台把「准备数据 → 跑实验 → 看报告 → 和 QuantLab 比」做成点按钮就能完成的桌面流程，同时保留 Qlib 原汁原味的计算。

![架构图](<assets/architecture.svg>)

- **窗口**（pywebview：macOS WKWebView / Windows WebView2）显示网页界面，网页只和本机服务通信。
- **本机服务**（主进程里的线程，只监听 `127.0.0.1` 的随机端口，带随机令牌）提供界面、数据、报告、使用指南接口，管理任务。
- **工作进程**（同一个程序加 `--worker` 参数）在需要时启动，调用上游 Qlib：`dump_bin` 写数据、`Alpha158` 算因子、`LGBModel` 等训练、`backtest` 回测；结束即退出。
- **数据**全部在用户数据目录（第 3 节）。**外部服务**只有两个，都是你主动点按钮才会连：本机的富途 / moomoo OpenD、GitHub 上的社区数据集。

详细的模块组织、调用链、手写文件职责和源码阅读路线见 [02 软件框架与系统架构](<02 软件框架与系统架构.md>) 和
[03 源码阅读与重建指南](<03 源码阅读与重建指南.md>)。完整源码（我们写的外壳 + 上游 Qlib）在「使用指南」左侧目录「源码」里逐个只读查看，
或点「下载全部源码（zip）」，目录结构与仓库 `qlib-studio/` 相同。

## 7. 当前进程与内存

「运行状态」页列出本次启动涉及的**每个进程**，每 3 秒重新读取，不用旧值：

| 列 | 含义 |
| --- | --- |
| 职责 | 主进程（窗口 + 本机服务 + 任务管理）、工作进程（写明正在跑哪个任务）、WebView2 子进程（Windows 上窗口网页渲染）等 |
| 进程名、PID | 和活动监视器 / 任务管理器里看到的一致 |
| 内存（MiB） | macOS / Linux 用**常驻内存 RSS**，Windows 用**工作集（Working Set）**；1 MiB = 1024² 字节 |
| 采样时间 | 本次读取的时间 |

- 没有任务时只有主进程（和 Windows 上的 WebView2 子进程），页面写明「**无独立后台**」：本机服务和任务管理是主进程里的线程，共用主进程 PID，线程不是进程。
- 有任务时多一个「工作进程」，任务结束后它从列表里消失，不保留已结束进程的旧数值。训练大数据集时工作进程可能占几百 MB 到几 GB。
- 合计是各进程数值相加，进程间共享的内存（例如同一程序文件的代码段）可能被重复计算。
- 读不到的值显示「暂不可用」。macOS 的 WKWebView 网页内容进程由系统托管（活动监视器里叫 `com.apple.WebKit.*`），不是本应用的子进程，这里读不到。
- **外部依赖单独列出、不计入合计**：富途 / moomoo OpenD 如果在本机运行，会显示它的 PID 和内存（它是你自己启动的独立程序，退出本应用不会关掉它）。
- 口径差别：Windows 任务管理器「详细信息」默认显示「专用工作集」，比这里的工作集小；macOS 活动监视器「内存」列不是 RSS，数值会有差别。要对照可以在活动监视器里双击进程看「实际内存」，或在任务管理器里加「工作集（内存）」列。

## 8. 怎样缩放界面

缩放控件在**顶栏右侧、「退出」按钮左边**，是紧凑的一组：「−」、百分比下拉框、「＋」、「↺」。

- 范围 **70%–120%，每 5% 一档，共 11 档**：70、75、80、85、90、95、100、105、110、115、120。
- 点百分比下拉框直接选档位；点「−」「＋」每次减 / 加 5 个百分点。到 70% 时「−」变灰，到 120% 时「＋」变灰。下拉框和按钮显示同一个当前值。
- 点「↺」恢复 100%（已经是 100% 时变灰）。快捷键：Ctrl（macOS 用 ⌘）加「−」「＝」「0」。
- 缩放作用于整个界面：文字、按钮、表格、图表和使用指南。切换页面、刷新和重新打开应用后保留你的选择（存在窗口组件的本机存储里）。
- 窗口很窄时顶栏会换行，缩放控件和「退出」仍在顶栏里，两种操作都可用。和系统显示缩放（Windows 125%、150%）叠加后也能正常使用。
