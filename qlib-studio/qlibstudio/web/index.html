获取数据

四种来源，最后都统一转成 Qlib 格式（上游 scripts/dump_bin.py）。每次只运行一个任务，进度显示在顶部状态条。

没有真实数据时先用它跑通流程。和 QuantLab 用同一个「模拟 A 股」生成器：放了几个弱规律（短期反转、中期动量、放量反转、低波动溢价）， 也有涨跌停、停牌、晚上市、退市和送转除权，外加一只模拟指数。不是真实行情。

300 只 × 6 年约 30 秒

支持：通达信 vipdoc 文件夹（sh/lday/*.day、sz/lday/*.day、bj/lday/*.day，不复权原始价格）、 通达信「数据导出」的 txt、CSV / TSV / Excel / Parquet（中英文列名自动识别：日期、开盘、最高、最低、收盘、成交量、成交额，可选代码、名称、复权因子）。 一个文件可以是一只股票，也可以带「代码」列放多只。读取逻辑与 QuantLab 相同。

当前是模拟 OpenD（环境变量 QLIBSTUDIO_FAKE_FUTU=1，只用于测试和演示），数据是生成的，不是真实行情。

需要先在本机打开 富途 OpenD 或 moomoo OpenD 并登录账号（下载地址和步骤见「使用指南 → 01 使用指南 → 富途 OpenD」）。 本应用只连本机 127.0.0.1，默认端口 11111。每只股票请求不复权和后复权两份，算出复权因子。

已在本地缓存覆盖的日期不再请求；30 天内重复请求同一只股票不额外占用额度
本地缓存（0 只）

社区维护的 A 股数据集 chenditc/investment_data：作者每天从多个公开来源交叉校验后发布 Qlib 格式的 qlib_bin.tar.gz （约 570 MB，解压后约 2–3 GB；含沪深 A 股日线、沪深 300 / 中证 500 等成分股和指数）。Qlib 官方数据集暂停下载后，上游 README 推荐用它。 国内网络访问 GitHub 可能很慢；下载中断后再点一次会从断点续传。

    实验记录

    点一行打开报告。数值都是测试区间（样本外）的结果。

    报告

    先在「实验」里运行一次，或从实验记录里选一个。

    净值 = 账户价值 ÷ 初始资金（已扣费用）。超额（Qlib 口径）= 每天（组合收益 − 基准收益）累加，与上游 PortAnaRecord 的 excess_return 一致。

    IC = 每天预测分数与下一期收益的皮尔逊相关；RankIC 用排名（斯皮尔曼）。柱子是每天的值，折线是 20 日均值。上游函数 qlib.contrib.eva.alpha.calc_ic。
