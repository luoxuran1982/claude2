## 1. 怎样开始和结束

### 安装与首次打开

**Windows（10/11，x64）**

1. 下载 `QuantLab-Setup-<版本>-x64.exe`，双击安装。装在 `%LOCALAPPDATA%\Programs\QuantLab\`，不需要管理员权限。
2. SmartScreen 提示「已保护你的电脑」时，点「更多信息 → 仍要运行」（安装包没有代码签名）。
3. 从开始菜单或桌面快捷方式「QuantLab 量化学习实验室」打开。
4. 界面用系统自带的 Microsoft Edge WebView2 显示（Windows 10/11 一般已装好）。没有 WebView2 时会自动改用默认浏览器打开，见下文「浏览器模式」。

也可以用免安装版：解压 `QuantLab-<版本>-windows-x64.zip`，双击里面的 `QuantLab.exe`。

**macOS（Apple Silicon）**

1. 下载 `QuantLab-<版本>-macos-arm64.dmg`，双击打开，把 `QuantLab.app` 拖进「应用程序」。
2. 第一次打开：在「应用程序」里右键 QuantLab →「打开」；或者先双击一次，再到「系统设置 → 隐私与安全性」点「仍要打开」（没有 Apple 开发者签名）。
3. 以后在「应用程序」或启动台里双击即可。
4. 界面用系统自带的 WebKit 显示，不需要另装浏览器。

> macOS 安装包是本版（1.1.0）新加的，由 CI 在 macOS Apple Silicon 机器上构建；在真实 Mac 上的安装、打开和退出**待用户验收**。

**首次准备**：本地导入不需要登录，也不需要开启任何外部服务。打开后先到「数据中心」导入 K 线、在线下载，或点「生成演示数据」。

- 用 **AKShare** 在线下载：只需要电脑能上网（访问东方财富、新浪、中证指数网站），不用注册账号。
- 用 **富途 / moomoo OpenD** 下载：先在本机安装并打开 OpenD（富途官网「OpenAPI」页下载），用牛牛号或 moomoo 账号登录，并开通 A 股行情权限。OpenD 是**外部独立程序**：本应用只连接它（默认 `127.0.0.1:11111`），不会启动它，退出本应用时也不会关闭它。

### 运行方式

| 运行方式 | 什么时候出现 | 界面在哪 |
| --- | --- | --- |
| 窗口模式（默认） | 正常双击打开 | 应用自己的窗口 |
| 浏览器模式 | 窗口组件不可用（如 Windows 缺 WebView2），或从源码用 `python run.py --browser` 启动 | 默认浏览器的一个标签页 |
| 服务模式 | 开发/测试用 `--serve-only` | 只有本机服务，没有界面 |

当前是哪种方式，在「运行状态」页能看到。

### 退出与关窗时会发生什么

本应用**只有一个进程**：本机 HTTP 服务和计算任务都是这个进程里的线程，没有独立的后台进程（见第 7 节）。

| 你的操作 | 结果 |
| --- | --- |
| Windows：点窗口右上角 ×、Alt+F4、任务栏右键「关闭窗口」 | 应用退出：取消正在运行的计算任务，结束本应用启动的子进程（包括 WebView2 的进程），关闭本机服务并释放端口 |
| macOS：点窗口左上角红色按钮（关闭唯一的窗口）、菜单「退出」、⌘Q、程序坞右键「退出」 | 同上 |
| 最小化、隐藏、切换到其他应用 | 应用和计算任务继续运行，回来后接着看进度 |
| 浏览器模式下关闭浏览器标签页 | 后台**不会**立刻退出：关闭页面 10 分钟后、且没有正在运行的任务时自动退出；想马上退出可在启动它的终端按 Ctrl+C |

应用只有一个主窗口，所以「关闭最后一个窗口」就是关闭这个窗口。

退出时**不会**删除任何数据或设置：数据集、实验结果、界面缩放等都保留。正在运行的实验会被取消，已完成的实验结果不受影响；被取消的那一次需要重新运行。

**崩溃或被强制结束时**：因为本机服务就在主进程里，进程一结束，服务和端口随之消失，不会留下后台进程。Windows 上 WebView2 的进程会在宿主进程消失后自行退出（这是 WebView2 运行时的行为）。打开文件夹时调用的资源管理器 / 访达是系统程序，不属于本应用。

## 2. 怎样完成主要任务

### 最常用的顺序

1. **数据中心**：导入通达信 `vipdoc` 文件夹或 CSV/Excel 文件夹，或「在线下载 A 股日线」（AKShare / 富途 OpenD）；没有数据就先「生成演示数据」。
2. **因子研究**（可选）：看哪些因子在你的数据上有效。
3. **新建实验**：选股票池、因子、模型、回测参数，点「开始实验」。
4. **实验结果**：看净值、回撤、IC、分层收益、交易记录。
5. **最新选股**：看模型对数据里最后一个交易日的排序。

### 各页面

| 页面 | 用途 | 主要按钮 |
| --- | --- | --- |
| 📂 数据中心 | 导入 K 线、在线下载、生成演示数据、管理数据集、看 K 线和数据来源 | 「选择文件夹…」「开始导入」「合并到已有数据集」（增量更新）；「在线下载 A 股日线」卡片（AKShare / 富途 OpenD 两个标签、「查询额度」「开始下载」）；「生成演示数据」；数据集表格的「数据来源」「最后更新」列、删除；搜索代码看 K 线（每只股票下方显示来源和更新时间）、叠加实验信号 |
| 🧪 因子研究 | 单因子 RankIC 检验 | 「开始检验」；表头点击排序 |
| ⚙️ 新建实验 | 配置并运行一次实验 | 预设一键套用、「复制配置 JSON」、「开始实验」 |

| 🎯 最新选股 | 最终模型对最后一个交易日打分排序 | 「导出 CSV」、点「K线」看个股 |
| 🖥️ 运行状态 | 本应用的进程和内存 | 每 3 秒自动刷新 |
| 📖 使用指南 | 本项目全部文档和源码 | 左侧目录切换篇目；「下载全部源码（zip）」 |

导入、在线下载、实验、因子检验都在后台任务里运行，同一时间只跑一个。页面顶部会出现进度条，可看「日志」或「取消」。

**导出**：窗口模式下点导出会弹出「另存为」对话框；浏览器模式下直接下载。CSV 带 BOM，用 Excel 打开中文不乱码。「导出实验结果 JSON」把一次实验的配置、训练/测试区间、股票池、策略和基准的日收益、IC/RankIC 序列、主要指标和版本号写进一个 JSON 文件，字段逐个说明见 [03 实验结果导出格式](<03 实验结果导出格式.md>)；命令行 `QuantLab export <实验编号> 文件.json` 效果相同。

### 在线下载 A 股日线（1.2.0 新增）

在「数据中心」的「在线下载 A 股日线」卡片里，先选上方标签：

![在线下载卡片（AKShare 标签，1.2.0 截图）](<assets/online-akshare-1.2.0.png>)

![富途 OpenD 标签：OpenD 没开时「查询额度」给出的中文原因（1.2.0 截图）](<assets/online-futu-1.2.0.png>)

| | AKShare（免费，无需账号） | 富途 / moomoo OpenD |
| --- | --- | --- |
| 数据从哪来 | 东方财富网页接口（失败时自动改用新浪）；指数成分来自中证指数公司 | 你电脑上已登录的 OpenD |
| 需要准备 | 能上网 | 打开 OpenD 并登录，开通 A 股行情（沪深）；北交所富途不提供 |
| 股票范围 | 指数成分、全部 A 股、自选代码、已有数据集里的股票 | 指数成分、自选代码、已有数据集里的股票（**不支持全部 A 股**，因为有额度） |
| 额度 | 没有账户额度，但请求太快会被网站限流 | 有按账户的历史 K 线额度，见下文 |
| 默认请求间隔 | 0.5 秒 | 0.6 秒（富途限制每 30 秒最多 60 次） |

操作顺序：

1. 选**股票范围**：「指数成分」再选指数（沪深300、中证500、中证1000、上证50、科创50、创业板指、中证A500）；「自选代码」填 `600519, 000001, 300750`（逗号、空格、分号都行，也认 `600519.SH`、`sz300750`）；「写入到数据集里的全部股票」用于更新已有数据集。
2. 选**日期区间**（默认 2015-01-01 到今天）和**复权方式**：
   - **不复权价格 + 复权因子（推荐）**：下载不复权价和后复权价，算出复权因子。涨跌停、一手 100 股按真实价格判断，收益按复权价计算，和通达信导入后的口径一致；每只股票请求 2 次。
   - **前复权 / 后复权**：只下一种复权价，请求少一半；价格不是真实成交价，涨跌停判断基本不受影响，但一手的金额不准。前复权遇到新的分红送转时历史价格会整体变，增量更新会自动发现并整段重下。
   - **不复权**：导入后按涨跌停规则估算除权（和通达信 `.day` 一样），小额现金分红识别不到。
3. **写入到**：「新建数据集」并起名，或「更新：某数据集」做增量更新。
4. 勾选「同时下载基准指数」时，会顺带下载沪深300、中证500 指数作回测基准。
5. 点「开始下载」，顶部出现进度条；可看「日志」或「取消」（取消时已下载的部分会保存）。卡片下方会估算首次下载用时：全部 A 股约 5,300 只，推荐的复权方式下约 1.5 小时；沪深300 约 5 分钟。

**增量更新、不重复拉**：写入已有数据集时，本地数据已经到结束日期（按工作日算）的股票直接跳过，不发请求；只有一部分的，从本地最后一天开始补（多下的那一天用来核对价格：对不上说明期间有除权、复权价变了，就整段重下）；改了复权方式的股票也整段重下。用过的股票会记下「检查时间」。

**限速与重试**：每两次请求之间至少等「请求间隔」秒；网络错误或被限流时按 2、4、8 秒退避重试 3 次；连续 5 只都失败就停下（已下载的照样保存），并给出原因。单只失败（如区间内没数据）写进数据集的「导入提示」，不影响其他股票。

**富途历史 K 线额度**：富途按账户限制「最近 30 天内下载过历史 K 线的**不同股票数**」，额度多少取决于账户资产和交易情况（以富途官方说明为准）；30 天内重复下载同一只股票不占额度。点「查询额度」会显示「剩余 N · 已用 M（最近 30 天下载过 K 只）」。开始下载时会再查一次：本地已是最新的不请求；最近 30 天下载过的先下（不占额度）；新股票按剩余额度截断，下不了的列在数据集的「导入提示」里，等额度恢复后再点一次「开始下载」即可接着下。

**下载失败时的中文原因**（也会出现在进度条和提示里）：

| 提示 | 意思与处理 |
| --- | --- |
| 网络连接失败：访问不到数据网站… | 断网、代理/VPN 或公司网络拦截了东方财富/新浪；换网络或调整代理 |
| 数据网站拒绝访问或请求太频繁（HTTP 403/429） | 被限流：调大「请求间隔」（如 1~2 秒），稍后再试 |
| 数据接口返回的格式和预期不同… | 数据网站改版，akshare 需要升级（安装包版等下一版更新） |
| 所选区间没有数据 | 未上市、长期停牌或代码不对 |
| 连不上 OpenD（127.0.0.1:11111）：OpenD 没有运行… | 先打开 OpenD；或核对 OpenD 设置里的 API 端口，改「端口」 |
| OpenD 已启动但行情没有登录 | 在 OpenD 里登录账号 |
| 没有该市场的行情权限 | 在富途牛牛/moomoo 里开通 A 股行情 |
| 历史 K 线额度不足 | 减少股票数，或等 30 天滚动窗口释放额度 |
| 端口能连上，但没有完成 OpenD 握手 | 这个端口不是 OpenD 的 API 端口，或 OpenD 版本太旧 |

**结果在哪里**：所有结果都存在数据目录（左下角「打开数据目录」）：

```text
<数据目录>/
├── datasets/<数据集编号>/bars.parquet, meta.json     # 导入后的数据集
├── runs/<实验编号>/config.json, summary.json, nav.csv, trades.csv,
│                  predictions.parquet, picks.json, models/*.pkl
├── webview/                                          # 窗口组件的缓存（含界面设置）
└── quantlab.log                                      # 运行日志（最多约 6 MB，自动轮换）
```

数据目录：Windows `%LOCALAPPDATA%\QuantLab\`，macOS `~/Library/Application Support/QuantLab/`。

## 3. 数据从哪来、何时更新

- **来源**：
  - 你自己导入的本地文件（通达信 `.day`、通达信导出 txt、CSV/TXT/Excel、Tushare 日线导出文件、Parquet）；
  - 1.2.0 起的在线下载：**AKShare**（东方财富/新浪，免费）和**富途 / moomoo OpenD**（需要你自己的账号）；
  - 应用生成的**演示数据**（模拟行情，不是真实数据）。
  三种来源写进同一种本地数据集（`datasets/<编号>/bars.parquet`），之后的因子、实验、回测完全一样；同一个数据集里可以混合不同来源。
- **每只股票的来源和更新时间**：数据中心表格的「数据来源」列显示各来源的股票数（如「通达信 4800」「AKShare 120」），「最后更新」是数据集最后一次写入的时间；在 K 线查看器的股票列表里，每只股票下方显示「来源 · 更新」，K 线标题旁也有。1.2.0 之前导入的数据集没有逐只记录，按数据集整体显示（通达信 / 本地文件 / 演示数据，时间取导入时间）。
- **更新**：没有自动或定时更新（**未实现**），都是你点按钮才更新：在线下载选「更新：某数据集」做增量；本地文件就用新数据再导入一次，并在「合并到已有数据集」里选原来的数据集（新数据覆盖重叠日期，复权因子重算）。
- **口径与单位**：日线；价格单位元；成交量统一成股；成交额统一成元（Tushare 的「手」「千元」、AKShare 东方财富接口的「手」都会自动换算）。界面 K 线是前复权（最新价格与真实一致）；回测用复权后的收益。
- **复权**：数据自带复权因子时直接用；不复权数据（如通达信 `.day`）用涨跌停规则识别送转除权跳空做近似复权，小额现金分红识别不到。
- **缺失、零、失败要区分**：
  - 某天没有这只股票的行：视为停牌，那天不能买卖。
  - 成交量为 0：视为停牌。
  - 文件读不出来：记为「读取失败」写进数据集的提示信息（数据中心表格的「提示」列），不会当成 0。
  - 在线下载失败：记为「下载失败 <代码>：<原因>」；区间内没有数据记为「所选区间没有数据」；富途额度不够没下的记为「历史 K 线额度不够，本次没有下载」。这些股票不会被写成 0 或空行。
  - 没有名称文件：名称为空，ST 识别不了（不是「不是 ST」）。
- **缓存**：样本矩阵在内存里缓存，导入、生成演示数据或删除数据集后清空；数据集和实验结果落盘保存，关掉应用也还在。

## 4. 结果如何理解

| 指标 | 读法 |
| --- | --- |
| 年化收益、最大回撤、夏普、卡玛 | 组合回测净值算出；夏普 = 年化收益 / 年化波动，卡玛 = 年化收益 / 最大回撤 |
| RankIC | 每期模型打分与未来收益排名的相关系数，再取平均。A 股日频选股 0.03~0.08 算不错；超过 0.15 多半有问题（未来函数、幸存者偏差、数据错误） |
| ICIR | IC 均值 / IC 标准差，衡量稳定性 |
| 分层收益 | 每期按打分把股票分 5 组；第 5 组应最好，且单调 |
| 信息比率 | 相对基准的超额收益 / 跟踪误差 |
| 年换手 | 一年成交额是平均资产的几倍；越高手续费越多 |

**适用范围与限制**：只做日频、只做多、A 股规则（T+1、100 股一手、涨跌停、印花税、最低佣金 5 元）。成交价按开盘价加滑点，大资金的冲击成本被低估。通达信本地目录通常没有退市股，回测偏乐观（幸存者偏差）。ST 只按当前名称识别。详见 [方案设计](<方案设计.md>) 的「已知局限」。

**指数成分的幸存者偏差**：在线下载的「指数成分」只有**当前**成分股，历史上被调出的股票不在里面，回测会偏乐观；做严肃研究请用「全部 A 股」。

**未实现**：行业/市值中性化、超参数搜索、分钟线因子、基本面数据、模拟盘、定时自动下载、港股/美股（富途 OpenD 只接了 A 股）。

## 5. 出了问题怎么办

按这个顺序查：

1. **看日志**：数据目录里的 `quantlab.log`，最后几十行通常就有原因。
2. **自检**：命令行运行 `QuantLab.exe --selftest 结果.json`（macOS：`/Applications/QuantLab.app/Contents/MacOS/QuantLab --selftest ~/selftest.json`），会用演示数据跑一遍完整实验，`"ok": true` 表示依赖都正常。
3. 常见情况：

| 现象 | 原因与处理 |
| --- | --- |
| Windows 上打开后变成在浏览器里 | 没有 WebView2 或窗口创建失败；功能一样。可从微软官网安装 WebView2 Runtime |
| macOS 提示「无法打开」「已损坏」 | 没有签名：右键 →「打开」，或「系统设置 → 隐私与安全性」点「仍要打开」 |
| 杀毒软件拦截 / 删除 `QuantLab.exe` | PyInstaller 打包的程序偶尔被误报；把安装目录加入信任，或改用免安装 zip |
| 导入后数据集是空的 | 选错了目录：通达信要选 `vipdoc`；看导入日志里识别到的文件数 |
| 数据没更新 | 应用不会定时自动下载：在线下载时在「写入到」选原数据集再点「开始下载」；本地文件先在通达信里「盘后数据下载」，再导入并合并到原数据集 |
| 在线下载失败 | 看进度条的失败原因和数据集「导入提示」，对照上文「下载失败时的中文原因」表；AKShare 失败多半是网络或限流，富途失败多半是 OpenD 没开/没登录/没权限/额度 |
| 富途「查询额度」一直转 | 端口能连上但 OpenD 没回应：最多等约 10 秒会给出原因；确认端口是 OpenD 的 API 端口 |
| 实验很慢或内存不够 | 缩短时间范围、提高流动性门槛、少选板块；在「运行状态」页看内存 |
| 点按钮提示「请求来源不允许」 | 页面令牌失效（例如应用重启后旧标签页还开着）：关掉旧页面，重新打开应用 |
| 端口被占用 | 应用每次随机选空闲端口，一般不会冲突；退出后端口即释放 |

## 7. 当前进程与内存

在左侧导航「🖥️ 运行状态」（或顶部右侧「运行状态 … MiB」按钮）查看，每 3 秒刷新一次。

**列出什么**：本次启动涉及的每个本应用进程，每行一个：职责、进程名、当前 PID、内存、线程数；表头上方是采样时间。

| 进程 | 说明 |
| --- | --- |
| 主进程 | 窗口 + 本机 HTTP 服务 + 计算任务。Windows 上是 `QuantLab.exe`，macOS 上是 `QuantLab` |
| 窗口渲染子进程（WebView2） | 仅 Windows：WebView2 启动的 `msedgewebview2.exe`，每个单独列出 |
| 计算子进程 | 若某项计算启动了子进程，运行期间会列出；结束后自动从列表消失（目前的模型训练用线程，一般不会出现） |
| 打开文件夹 | 点「打开数据目录」时短暂出现的系统程序 |

**没有独立后台**：页面会明确显示「无独立后台：本机 HTTP 服务和计算任务都是主进程里的线程」。导入、实验、因子检验在主进程的线程里运行，所以不会多出 PID；同一进程的线程共享 PID，线程数不是进程数。

**应用外部的独立依赖**：只有富途 / moomoo OpenD（仅在用富途数据源时）。本次启动里用过「查询额度」或富途下载后，「运行状态」页的「外部依赖」一行会单独列出 OpenD 的进程名、PID 和内存（找不到时说明原因），**不计入本应用合计**，退出本应用时也不会关闭它。AKShare 只是主进程里的网络请求，没有单独的进程。futu-api 与 OpenD 通信用的是主进程里的线程。

**口径和单位**：

- macOS：常驻内存 RSS；Windows：工作集（Working Set）；单位 MiB（1 MiB = 1024² 字节 = 1,048,576 字节）。
- Windows「任务管理器」默认的「内存」列是**专用工作集**，不含与其他进程共享的部分，所以通常比这里显示的工作集小。要对照，可在任务管理器「详细信息」页右键表头勾选「工作集(内存)」。
- macOS「活动监视器」默认的「内存」列不是 RSS，数值会有差别；可在「显示 → 列」里加「实际内存」对照（大致对应 RSS）。
- 合计是各进程内存直接相加，进程间共享的内存可能被重复计算。
- 读不到时显示「暂不可用」，不会用旧 PID 或估算值代替。

**已知限制**：macOS 上 WebKit 的网页内容进程（`com.apple.WebKit.WebContent`）由系统托管，不是本应用的子进程，目前列不出来（未实现）。

## 8. 怎样缩放界面

缩放控件在**窗口顶部右侧**，是紧凑的一组：

```text
[ − ] [ 100% ▾ ] [ ＋ ] [ 恢复 100% ]
```

- **选择具体档位**：点中间的百分比下拉框，从 70%、75%、80%、85%、90%、95%、100%、105%、110%、115%、120% 共 11 档里选。
- **逐档调整**：点「−」减 5 个百分点，点「＋」加 5 个百分点。到 70% 时「−」变灰不可点，到 120% 时「＋」变灰不可点。
- **恢复**：点「恢复 100%」。默认就是 100%。
- 下拉框和按钮始终显示同一个当前值。
- 缩放作用于整个界面：文字、按钮、表格、图表（缩放后自动重绘）和使用指南里的文档、源码。
- 切换页面、重新打开应用后，保留你上次选的档位（保存在窗口组件的本地存储 localStorage 里；浏览器模式下保存在浏览器里）。
- 它和系统的显示缩放（如 Windows 的 125%、150%，macOS 的「缩放」分辨率）叠加生效。窗口很窄时，顶部控件会自动换行，仍然可用。
