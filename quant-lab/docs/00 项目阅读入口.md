## 这是什么

QuantLab 量化学习实验室是一个**本地桌面应用**：用你电脑里的日 K 线数据（通达信、CSV、Excel 等），做「机器学习选股 + A 股规则回测」的学习和研究。所有计算都在本机完成，不联网、不需要账号。

> 仅供学习研究，不构成投资建议。

- 当前版本：**1.1.0**（界面左下角和顶部标题旁都显示版本号）
- 应用名称：QuantLab 量化学习实验室（程序文件名 `QuantLab`）
- 平台：Windows 10/11 x64；macOS（Apple Silicon，M 系列芯片）

## 安装和打开

| | Windows | macOS |
| --- | --- | --- |
| 安装包 | `QuantLab-Setup-<版本>-x64.exe`（另有免安装 zip） | `QuantLab-<版本>-macos-arm64.dmg`，里面是 `QuantLab.app` |
| 安装位置 | `%LOCALAPPDATA%\Programs\QuantLab\`，不需要管理员权限 | 把 `QuantLab.app` 拖进「应用程序」：`/Applications/QuantLab.app` |
| 打开 | 开始菜单或桌面快捷方式「QuantLab 量化学习实验室」 | 「应用程序」或启动台里双击 QuantLab |
| 首次打开的安全提示 | SmartScreen：点「更多信息 → 仍要运行」 | 右键 →「打开」，或「系统设置 → 隐私与安全性」点「仍要打开」 |
| 卸载 | 「设置 → 应用」或开始菜单里的卸载快捷方式 | 把 `QuantLab.app` 拖进废纸篓 |

安装包由 GitHub Actions 构建（工作流 `.github/workflows/quant-lab.yml`），在仓库 Actions 页面对应的运行里下载；打 `quant-v<版本>` 标签时会发布到 Release。两个安装包都没有代码签名。

详细步骤和启停行为见 [01 使用指南](<01 使用指南.md>)。

## 几个目录不要混淆

| 目录 | 是什么 | 位置 |
| --- | --- | --- |
| 源码目录 | 仓库里的 `quant-lab/`：Python 引擎、网页界面、打包脚本、测试、文档 | GitHub 仓库 |
| 安装目录 | 安装后的程序文件（只读，升级时整体替换） | Windows `%LOCALAPPDATA%\Programs\QuantLab\`；macOS `/Applications/QuantLab.app` |
| 数据目录 | 导入的数据集、实验结果、日志、窗口缓存（升级和卸载都**不会**删除） | Windows `%LOCALAPPDATA%\QuantLab\`；macOS `~/Library/Application Support/QuantLab/` |
| 文档目录 | 本目录 `quant-lab/docs/`，同时是应用内「使用指南」的来源，也同步到 Obsidian | 仓库；安装包里也带了一份 |

想把数据放到别处：设置环境变量 `QUANTLAB_DATA` 指向新目录。
