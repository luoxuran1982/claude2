# QuantLab 量化学习实验室 —— 安装说明（Windows）

## 方式一：安装程序（推荐）

1. 下载 `QuantLab-Setup-1.0.0-x64.exe`，双击安装（装在当前用户目录，**不需要管理员权限**）。
2. 桌面会出现“QuantLab 量化学习实验室”图标，双击打开。
3. 第一次打开如果 Windows SmartScreen 提示“已保护你的电脑”：点“更多信息” → “仍要运行”（安装包没有购买代码签名证书）。

界面使用系统自带的 **Microsoft Edge WebView2**（Windows 10/11 一般已经装好）。如果没有，程序会自动改用默认浏览器打开，功能完全一样。

## 方式二：免安装版

下载 `QuantLab-1.0.0-windows-x64.zip`，解压到任意文件夹（路径里最好不要有特殊符号），双击 `QuantLab.exe`。

## 方式三：从源码运行（适合想改代码的人）

1. 安装 Python 3.10 ~ 3.13（https://www.python.org/downloads/ ，安装时勾选 **Add python.exe to PATH**）。
2. 双击 `start-windows.bat`：第一次会自动创建虚拟环境并安装依赖（几分钟），之后秒开。
   - 国内网络慢可以先设置镜像：`pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`
3. 命令行用法见 `docs/使用说明.md`。

## 数据放在哪里

- 导入的数据集、实验结果、日志：`%LOCALAPPDATA%\QuantLab`（界面左下角“打开数据目录”）
- 卸载程序**不会删除**这些数据；要彻底清理，手动删除这个文件夹。
- 想换位置：设置环境变量 `QUANTLAB_DATA=D:\QuantLabData`。

## 电脑配置建议

| 数据规模 | 内存 | 一次实验耗时（参考） |
| --- | --- | --- |
| 演示数据 300 只 × 8 年 | 4 GB | 约 1 分钟 |
| 全 A 约 5000 只 × 10 年 | 16 GB | 10~20 分钟 |

内存不够时：缩小时间范围、提高“20 日均成交额”门槛、或只选部分板块。

## 遇到问题

- 打不开 / 闪退：看 `%LOCALAPPDATA%\QuantLab\quantlab.log` 最后几十行。
- 自检：在命令行运行 `QuantLab.exe --selftest 结果.json`，会用演示数据跑一遍完整实验，`"ok": true` 表示所有组件正常。
