# QuantLab 使用说明

## 1. 导入数据

**数据中心 → 导入本地 K 线**，填文件夹路径（或点“选择文件夹…”），点“开始导入”。子文件夹会一起扫描。

### 支持的格式

| 来源 | 怎么导 | 说明 |
| --- | --- | --- |
| **通达信本地数据** | 选 `通达信安装目录\vipdoc`（下面有 `sh\lday`、`sz\lday`、`bj\lday`） | 二进制 `.day`，不复权；自动识别除权跳空做近似复权。先在通达信里“盘后数据下载”把日线补全 |
| 通达信“数据导出” | 选导出的文件夹（`.txt`/`.csv`） | 首行“600519 贵州茅台 日线 前复权”会被识别：名称、是否复权都自动读出 |
| 通用 CSV / TXT / Excel | 选文件夹或单个文件 | 列名中英文都行：日期/date/trade_date、开盘/open、最高/high、最低/low、收盘/close、成交量/volume/vol、成交额/amount、代码/code/ts_code、名称/name |
| 一个文件多只股票 | 同上 | 需要有“代码”列 |
| Tushare `daily` | 同上 | `vol`（手）、`amount`（千元）自动换算；有 `adj_factor` 列就用它精确复权 |
| 分钟线 | 同上 | 同一天多行会自动聚合成日线 |
| Parquet | 同上 | 列名规则同 CSV |

**股票名称 / ST 识别**：通达信 `.day` 文件里没有名称。在同一个文件夹里放一个只有“代码、名称”两列的 CSV/Excel（例如在通达信行情列表里“导出”→ Excel），导入时会自动读取，界面就能显示名称，“排除 ST”也能生效。

代码写法都能识别：`600000`、`600000.SH`、`SH600000`、`sh.600000`、`600000.XSHG`。只有 6 位数字时按股票规则推断市场（`000001` 视为平安银行；指数请带前缀，如 `sh000001`）。

**增量更新**：以后有新数据时，导入时在“合并到已有数据集”里选原来的数据集，新数据覆盖重叠日期，复权因子自动重算。

**基准指数**：导入时勾选“同时导入指数”，通达信目录里的 `sh000300`（沪深 300）、`sh000905`（中证 500）等就能在回测里当基准。

## 2. 因子研究（可选）

选数据集、预测周期，点“开始检验”。表格按 |RankIC| 排序：
- RankIC 为负表示“反向有效”（比如 5 日涨幅越大，未来越跌 = 短期反转）；
- 胜率（IC>0 占比）接近 50% 的因子不稳定；
- “IC 走势”小图看它是不是只在某几年有效。

## 3. 新建实验

上方有预设可以一键套用。各区块含义：

- **股票池（掩码）**：板块、上市天数、流动性门槛、是否排除 ST。每个决策日只在当天有成交、满足条件的股票里选。
- **因子**：按组勾选，或直接填因子名。
- **预测目标**：预测几天后的收益；建议保持“次日开盘买 → N 日后开盘卖”，和回测一致。
- **模型**：可多选，等于等权集成。高级参数用 JSON，例如 `{"lgbm": {"num_leaves": 31, "learning_rate": 0.03}}`。
- **滚动训练**：训练窗口 750 个交易日（约 3 年）、每 63 天（约一季度）重训。训练集与测试集之间自动留隔离带。
- **回测**：持仓只数、调仓周期、资金、费用、缓冲倍数、止损、基准。

> 调仓周期同时也是“决策日”的间隔：每个决策日都会出预测、做训练样本、调仓。预测周期和调仓周期设成一样（5/5、20/20）最自然。

## 4. 看结果

- **概览**：净值 vs 基准、相对强弱、回撤。
- **模型评估**：每期 RankIC 与累计 RankIC（累计线稳步向上才可信）、分 5 组的累计收益（第 5 组应最好、且单调）、因子重要性、单因子 IC。
- **交易记录**：每一笔买卖、费用、盈亏；点代码跳到 K 线，图上标出买卖点和模型得分。
- **月度收益**、**当前持仓**、**训练过程**（每一段的训练/测试区间、验证集 RankIC、迭代次数）、**配置**。
- **实验对比**：勾选多个实验，净值叠加、指标并排。
- **最新选股**：用最近数据训练的最终模型，对数据里最后一个交易日打分排序。

### 怎么判断结果靠不靠谱

1. 年化收益很高但 RankIC 很低（<0.02）→ 可能是运气或少数股票贡献，看交易记录。
2. RankIC 超过 0.15 → 大概率有问题（未来信息、幸存者偏差、数据错误）。
3. 把“结束日期”设在一年前做研究，最后再用最近一年验证一次（只看一次）。
4. 年换手几十倍时，手续费会吃掉大部分收益：加大调仓周期、缓冲倍数。

## 5. 命令行

和界面共用数据目录（`%LOCALAPPDATA%\QuantLab`），源码目录下：

```bash
python run.py demo --stocks 300 --years 8             # 生成演示数据
python run.py import D:\new_tdx\vipdoc --title 通达信  # 导入
python run.py import D:\export --merge-into ds20261007_101010   # 增量合并
python run.py list                                    # 列出数据集和实验
python run.py factors --dataset demo --horizon 5      # 单因子检验
python run.py run my.json                             # 按配置运行实验
python run.py --browser                               # 用浏览器打开界面
```

配置 JSON 只需要写和默认值不同的部分（界面“复制配置 JSON”可以导出完整配置）：

```json
{
  "name": "全A-LGBM-5日",
  "dataset": "ds20261007_101010",
  "period": {"start": "2016-01-01", "end": "2025-12-31"},
  "universe": {"boards": ["sh_main", "sz_main", "chinext"], "min_amount": 30000000},
  "label": {"horizon": 5},
  "model": {"types": ["lgbm", "ridge"]},
  "backtest": {"top_k": 30, "rebalance_days": 5, "benchmark": "sh000905"}
}
```

## 6. 扩展（改代码）

- **加因子**：在 `quantlab/features.py` 里用 `@feature("名字", "分组", "说明")` 装饰一个函数，输入 `ctx`（有 `C/O/H/L/V/A` 复权宽表、`ret`、`mkt` 等），返回同形状宽表。只能用 `shift(正数)`/`rolling` 这类向后看的运算。
- **加模型**：在 `quantlab/models.py` 写一个继承 `Base` 的类（实现 `fit/predict`），放进 `REGISTRY`，再在 `config.MODEL_TYPES` 里加显示名。
- 改完运行 `python -m unittest discover -s tests -v`，其中“截断一致性”测试会自动检查新因子有没有偷看未来。
