# QuantLab 方案设计：用机器学习研究 A 股

这份文档回答三个问题：**可以怎么做**（发散的方案）、**这一版选了什么、为什么**、**接下来可以往哪走**。

---

## 1. 问题拆解

“用 K 线 + 机器学习做股票”本质上是一条流水线，每一环都有好几种做法：

```
本地K线 → 清洗/复权 → 股票池与交易掩码 → 因子(特征) → 标签(预测什么) → 模型 → 滚动训练 → 评估 → 组合回测 → 选股/实盘
```

最容易出错、也最影响结论真伪的不是模型，而是 **数据（复权、幸存者偏差）**、**时间对齐（未来函数）** 和 **交易约束（T+1、涨跌停、停牌、手续费）**。所以这个系统把大部分工程量放在这些地方。

## 2. 发散：每一环的可选方案

### 2.1 预测什么（问题定义）

| 方案 | 说明 | 适合 | 本版 |
| --- | --- | --- | --- |
| **截面选股**（排序） | 每天给全市场股票打分，买前 K 只 | 有全市场 K 线，最成熟、信噪比最高 | ✅ 主线 |
| 单股择时 | 预测某只股票/指数明天涨跌，决定持仓/空仓 | 只关心少数标的 | ⏳ 路线图 |
| 行业/风格轮动 | 预测行业指数相对强弱 | 有行业分类数据 | ⏳ |
| 事件驱动 | 涨停次日、放量突破等特定形态之后的收益 | 打板/短线研究 | 部分（涨停次数因子） |

截面选股是首选：不需要预测大盘涨跌（最难），只需要判断“谁比谁强”，而且一天有几千个样本，统计上稳得多。

### 2.2 标签

- **未来 N 日收益**（本版默认 5 日，次日开盘买 → N 日后开盘卖，和回测完全一致）
- **超额收益**：减去当天股票池均值，去掉大盘涨跌的噪声（默认开）
- **截面排名 / Z 分数**：让每天的标签同分布，模型更稳（默认排名）
- **分类**：是否进入前 30%（`lgbm_cls`）；**排序学习**：LambdaRank 直接优化排序（`lgbm_rank`）
- 可扩展：风险调整收益（收益/波动）、三重障碍法（止盈/止损/到期先到哪个）

### 2.3 特征（因子）

本版内置 73 个纯量价因子，分 9 组：动量、均线、波动、价格位置、经典指标（RSI/MACD/KDJ/布林/CCI/WR/ATR/OBV）、量能/流动性（量比、Amihud、价量相关）、K 线形态（影线、跳空、日内/隔夜收益）、分布/涨跌停、市场相对（Beta、特质波动、相对强弱）。

所有因子都只用 t 日及以前的数据；测试里有一条专门的“截断一致性”检验：用截至 t 日的数据和用全部数据算出的 t 日因子必须完全相同。

可以继续加的方向：
- **Alpha158/Alpha360 风格**的大规模量价因子（Qlib）；遗传规划自动挖因子
- **基本面**（PE/PB/ROE/营收增速，需要财报数据）、**资金流**（龙虎榜、北向、融资融券）
- **分钟线衍生**的日频因子（尾盘成交占比、日内波动结构）
- **文本/情绪**（新闻、公告、股吧）——数据门槛高

### 2.4 模型

| 模型 | 特点 | 本版 |
| --- | --- | --- |
| **LightGBM**（回归/排序/分类） | 表格数据的事实标准：快、抗噪、能处理缺失值、可解释（重要性） | ✅ 默认 |
| 随机森林 / sklearn 梯度提升 | 稳健基准 | ✅ |
| 岭回归 | 线性基准，看非线性到底带来多少增益 | ✅ |
| MLP 神经网络 | 简单深度模型 | ✅ |
| **集成** | 多模型每日排名取平均，通常比单模型稳 | ✅ 勾选多个即可 |
| LSTM / GRU / Transformer / TCN | 直接吃原始 K 线序列 | ⏳ 需要 PyTorch，安装包会大 1~2GB，作为可选插件 |
| 图神经网络 | 利用行业/供应链/相关性关系 | ⏳ |
| 强化学习 | 直接学交易动作 | ❌ 不推荐起步：样本少、极易过拟合 |

经验：A 股日频选股上，**好的特征 + LightGBM** 通常已经接近深度模型的效果，而且快几十倍、好调试。先把这条线跑扎实，再上深度学习做对比。

### 2.5 训练与验证

- ❌ 随机划分训练/测试集：会把未来信息泄露进训练，回测漂亮但实盘失效
- ✅ **滚动训练（walk-forward）**：每段测试期只用之前的数据训练，定期重训；训练与测试之间留“预测周期+1 天”的隔离带（purge）
- ✅ 训练窗口末尾切一段做验证集，**早停看验证集 RankIC**（不是 L2 损失）
- 可扩展：CPCV（组合清洗交叉验证）、超参数自动搜索（Optuna）——注意搜索本身也会过拟合

### 2.6 回测

- 事件驱动的逐日模拟：现金、持仓、100 股一手、佣金（最低 5 元）、卖出印花税、滑点
- **T+1**：t 日收盘出信号，t+1 日开盘成交
- **掩码**：一字涨停买不进（顺延下一只）、一字跌停卖不出（次日重试）、停牌不能交易、退市按最后价清算
- 持仓缓冲带（排名还在前 K×倍数就不换）、止损
- 基准：任意指数，或股票池等权

### 2.7 系统形态

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| Jupyter 笔记本 | 灵活 | 难复用，容易无意引入未来函数 |
| 命令行 + 配置文件 | 可批量、可复现 | 门槛高 |
| **桌面应用（本地 Web UI）+ 命令行** | 双击就用，图表交互好，同时保留脚本化能力 | 工程量大 | 
| 直接用 Qlib/Backtrader/vn.py | 生态成熟 | Windows 上安装折腾，A 股细节要自己补，界面需要另做 |

本版选择第三种：Python 引擎 + 本机网页界面（WebView2 独立窗口），打包成 Windows 安装程序；同一套引擎也能用命令行跑配置文件。

## 3. 本版架构

```
quantlab/
  data/readers.py   通达信 .day / 通达信导出 txt / CSV / Excel / Tushare / Parquet / 分钟线聚合
  data/adjust.py    不复权数据的除权识别（涨跌停规则 + 最小价位容差）
  data/store.py     数据集：导入、增量合并、parquet 存储、宽表 Panel
  data/demo.py      模拟 A 股（含涨跌停、停牌、送转、退市、弱规律）
  market.py         代码规范化、板块识别、涨跌停幅度（含创业板 2020-08-24 注册制切换）
  masks.py          股票池掩码、可买/可卖掩码、未来收益标签
  features.py       73 个因子（注册表，可扩展）
  dataset.py        样本矩阵：决策日 × 股票池，截面标准化，带缓存
  models.py         模型注册表（统一 fit/predict/importance）
  trainer.py        滚动训练 + 隔离带 + 最终模型
  evaluate.py       IC/RankIC/ICIR、分层收益、单因子检验
  backtest.py       A 股规则组合回测
  metrics.py        收益/风险/交易统计、月度表
  experiment.py     一次实验的完整流程与结果保存
  server.py app.py  本机服务 + 独立窗口
  cli.py            命令行
  web/              界面（原生 JS + ECharts）
```

## 4. 已知局限（务必了解）

1. **幸存者偏差**：通达信本地目录通常不含已退市股票，回测偏乐观。有条件时导入含退市股的完整数据。
2. **复权是近似的**：小额现金分红识别不到；有准确复权因子时优先用。
3. **ST 只能按当前名称识别**；历史名称变化不知道。
4. **成交价假设为开盘价 + 滑点**，大资金的冲击成本被低估。
5. 回测里的指数基准与股票数据需要来自同一数据源，否则日期对不齐。

## 5. 路线图（建议顺序）

1. 单股/指数择时模式（概率阈值 + 仓位管理）
2. 行业分类与行业中性化、市值中性化
3. 超参数搜索（Optuna）与稳健性报告（参数邻域、分年度表现）
4. PyTorch 序列模型插件（LSTM/Transformer），作为可选下载
5. 分钟线因子、基本面数据接入
6. 模拟盘：每天收盘后自动更新数据、出信号、记录虚拟成交
