    因子研究 单因子 RankIC 检验
    
    
    
      
    逐个检验因子与未来收益的截面秩相关（RankIC）。|RankIC| > 0.03 且胜率稳定的因子通常有用；负 IC 表示反向有效（例如短期反转）。树模型会自动组合它们。

    新建实验
    
    
    
      预设：
      
      
      
      
      
      
      
      
    
    
    
    
      
    
        
    ① 基本
    
        
    
          
          
          
          
        
    
        
    开始日期之前会自动多加载约 1.5 年数据给指标预热；回测从第一次滚动训练结束后开始。
    
      
    
      
    
        
    ② 股票池（掩码）
    
        
    
        
    
          
          
          
          
        
    
        
    每个决策日只在“当天有成交 + 上市够久 + 流动性够”的股票里选；次日一字涨停买不进、一字跌停卖不出、停牌不能交易。
    
      
    
      
    
        
    ③ 因子
    
        
    
        
    
          
          
        
    
      
    
      
    
        
    ④ 预测目标（标签）
    
        
    
          
          
          
          
        
    
      
    
      
    
        
    ⑤ 模型
    
        
    
        
    选多个模型 = 等权集成（每天把各模型的打分转成排名后取平均）。
    
        
    高级：模型参数（JSON，按模型名分组，留空用默认）
          
        
    
      
    
      
    
        
    ⑥ 滚动训练（walk-forward）
    
        
    
          
          
          
          
          
        
    
        
    训练集和测试集之间自动留出“预测周期 + 1 天”的隔离带，回测只用样本外预测，杜绝未来函数。
    
      
    
      
    
        
    ⑦ 回测
    
        
    
          
          
          
          
        
    
        
    
          
          
          
          
          
          
        
    
        
    决策日收盘出信号 → 次日开盘先卖后买、等权、100 股一手。持仓排名仍在前“持仓只数×缓冲倍数”内就不换，能明显降低换手和手续费。

    使用说明
    
    
    
      
    四步上手
    
      
      
        
    1. 数据中心：导入通达信 vipdoc 文件夹（或 CSV 文件夹），或先生成演示数据。
      2. 
        
    2. 因子研究（可选）：看看哪些因子在你的数据上有效。
      3. 
        
    3. 新建实验：选股票池、因子、模型、回测参数，点“开始实验”。全市场 10 年数据通常几分钟到十几分钟。
      4. 
        
    4. 实验结果：看净值、回撤、IC、分层收益、交易记录；最新选股看模型对最新一天的排序。
      5. 
      
    
      
    时间线（为什么没有未来函数）
    
      
    t 日收盘后用 t 日及以前的数据算因子、打分 → t+1 日开盘按打分买入 → 持有 N 天后开盘卖出。训练用滚动窗口，训练集最后一个样本的标签在测试开始前就已经实现（中间留隔离带），所以回测里的每一个预测都是“样本外”的。
    
      
    指标速查
    
      
    
        
    RankIC
    每天模型打分与未来收益排名的相关系数，再取平均。A 股日频选股 0.03~0.08 算不错，超过 0.15 要怀疑数据有问题（比如未来函数或幸存者偏差）。
    
        
    ICIR
    IC 均值 / IC 标准差，衡量稳定性。
    
        
    分层收益
    每天按打分把股票分 5 组，第 5 组应该收益最高，单调性越好越可信。
    
        
    夏普 / 卡玛
    年化收益 / 年化波动；年化收益 / 最大回撤。
    
        
    信息比率
    相对基准的超额收益 / 跟踪误差。
    
        
    年换手
    一年的成交额是平均资产的几倍。换手越高手续费越多，可以调大调仓周期、持仓缓冲倍数。
    
      
    
      
    常见坑
    
      
      
        
    • 幸存者偏差：通达信本地目录往往没有已退市股票，回测会偏乐观。
      • 
        
    • 复权：通达信 .day 是不复权价格，系统用涨跌停规则识别送转除权跳空做近似复权；有准确复权因子（如 Tushare adj_factor 列）时优先使用。
      • 
        
    • ST 识别只能依据当前名称，历史上曾经是 ST 的股票识别不到。
      • 
        
    • 不要反复在同一段数据上调参后只看最好的结果——那是过拟合。用“结束日期”留一段最近的数据最后再验证。
