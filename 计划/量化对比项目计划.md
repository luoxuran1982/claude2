# 量化对比项目计划

## 背景
- 对比对象：微软 Qlib（https://github.com/microsoft/qlib，MIT，约 4.9 万星）。思路和 QuantLab 一致（因子 → 模型 → 滚动训练 → 回测）。
- Qlib 官方数据集目前暂停下载；自带雅虎抓取脚本（质量一般）；推荐社区 A 股数据集 chenditc/investment_data 或用户自有数据。
- 用户有本地数据（通达信等）和 moomoo / 富途 OpenD 接口（本机 127.0.0.1:11111）。
- 不选：RD-Agent（只支持 Linux + Docker）、vn.py（偏实盘交易，数据多为付费）、Qbot（许可证冲突）、backtrader（停止维护）。

## 任务 A：新项目「Qlib 量化研究台」
- 分支 `claude/qlib-studio`，目录 `qlib-studio/`，上游源码放 `qlib-studio/upstream/`（固定 commit，保留 LICENSE，UPSTREAM.md 记录补丁）。
- 按《交付要求》全套：pywebview 窗口、全中文、使用指南（文档 + 源码查看/下载）、运行状态、70%–120% 缩放、退出停全部子进程、Mac .dmg + Windows Setup.exe/zip、CI 冒烟、Release。
- 页面：数据（通达信/CSV 导入、富途 OpenD 下载、社区数据集下载 → 转 Qlib 格式 + 质量检查）、实验（Alpha158/Alpha360；LightGBM/XGBoost/CatBoost/线性；训练区间；一键运行）、报告（收益曲线、回撤、IC、分层、持仓）、与 QuantLab 对比（读 QuantLab 导出的实验结果，同数据同区间并排）。
- 默认不打包 PyTorch（约 1 GB），深度模型做成可选下载；目标安装包 300–500 MB。
- 文档 00–04；04 = 与 QuantLab 对比（因子、模型、A 股规则：涨跌停/T+1/一手 100 股、回测假设、互相借鉴清单）。
- 富途 OpenD：历史 K 线有按账户的额度限制，界面显示剩余额度、本地缓存不重复拉；云端无 OpenD，用模拟接口测试，真实下载待用户验收。
